> 历史基线说明：本文保留 2026-10-20 P0 增补前的实现描述。后续已实现变化见[数字相册 P0 本地交付说明](ADMIN_DIGITAL_ALBUMS_P0_LOCAL_20261020.md)；包含模式分离与创建预览的最新完整需求见[Fan OS 相册功能 PRD V1.1](FAN_OS_ALBUM_PRD_V1_1_20261022.md)。最新需求稿中的新增能力不等同于已上线能力。

版本：V1.0（现状基线）  
核对日期：2026-10-20  
适用范围：Fan OS 管理后台 `/digital-albums` 及其关联的 App 行为。  
编写依据：当前仓库页面、接口、业务校验与已有测试代码；未连接生产数据库核验线上配置，本文默认值为代码默认值。

## 1. 模块定位

数字相册用于管理用户使用官方图鉴小卡创作的卡册作品，包含作品查看与公开限制、容量配置、用户 PRO 授权、系统主题及素材维护。

数字相册与用户上传私人照片、图鉴中的音乐专辑是不同业务对象。卡册内放置的是官方图鉴小卡的引用；同一张小卡可以在作品中多次出现，卡册放置行为不等于用户拥有该实体小卡。

当前管理后台承担以下职责：

1. 查询用户作品，查看当前编辑版本的内页和卡位。
2. 对作品限制公开或解除限制，记录处理原因。
3. 配置普通用户与 PRO 的相册数量、内页数量，以及全局每页卡位上限。
4. 按用户编号直接设置普通 / PRO 权益和到期时间。
5. 新增、编辑、上架或下架系统书架主题、符号贴纸及背景配置。

本文描述现有实现。另行讨论的付费会员价格、AI 扫描额度、付费素材包等不属于本模块当前已完成的功能。

| 操作 | 系统管理员 admin | 运营管理员 operation_admin | 内容运营 content_operator |
| --- | --- | --- | --- |
| 查看数字相册菜单 | 支持 | 支持 | 不展示 |
| 查询作品、查看详情 | 支持 | 支持 | 接口拒绝 |
| 限制公开 / 解除限制 | 支持 | 支持 | 接口拒绝 |
| 查看额度配置、素材列表 | 支持 | 支持 | 接口拒绝 |
| 修改全局额度与拦截词 | 支持 | 只读 | 接口拒绝 |
| 设置用户会员权益 | 支持 | 不可提交 | 接口拒绝 |
| 新增 / 编辑系统素材 | 支持 | 只读 | 接口拒绝 |

权限在页面按钮与服务端均有约束。普通 App 用户不能访问这些管理接口。运营管理员虽可查看“额度与会员”“主题与系统素材”页签，但配置表单和素材维护操作不可用。

## 3. 页面结构与公共操作

菜单入口：后台管理 → 数字相册。

页面含三个页签：

| 页签 | 主要内容 | 主要动作 |
| --- | --- | --- |
| 作品管理 | 筛选区、作品列表、详情抽屉 | 查看、限制公开、解除限制 |
| 额度与会员 | 全局额度及拦截词表单、指定用户授权表单 | 保存配置、取消修改、更新权益 |
| 主题与系统素材 | 素材列表、素材新增 / 编辑弹窗 | 新增系统素材、编辑、通过状态字段上下架 |

公共规则：

- 首次进入加载作品列表及相册配置、系统素材。
- 页头“刷新”重新加载作品、配置和素材，保留当前筛选条件。
- 加载失败展示错误提示和“重试”；保存失败显示接口返回原因。
- 保存操作展示加载状态并防止同一次提交重复触发；成功后提示并刷新数据。
- 额度和会员表单修改后，切换页签、点击刷新或取消时有未保存确认；素材表单使用公共弹窗的未保存保护。
- 当前没有独立统计仪表盘、批量作品处理或导出功能。

## 4. 作品管理

### 4.1 查询条件

| 字段 | 位置 | 当前查询规则 |
| --- | --- | --- |
| 相册名称 | 基础筛选 | 按相册名称包含关键词检索，不是作者昵称搜索 |
| 状态 | 基础筛选 | 全部状态、草稿、已发布、已删除 |
| 用户 ID | 高级筛选 | 按作者用户 ID 精确匹配 |
| 日期范围 | 高级筛选 | 按作品创建时间筛选，不是更新时间 |

交互与结果范围：

- 条件变化后自动查询，输入等待约 300ms，过期请求被取消或忽略。
- “高级筛选”展开 / 收起用户 ID 与日期条件；“重置”清除基础和高级条件。
- 日期起止由页面提交为起始日 `00:00:00` 至结束日 `23:59:59`，包含边界。
- 按作品更新时间倒序返回，单次最多 200 本。
- 列表默认每页 20 条，可调整每页条数。分页发生在本次已返回的数据内，不能翻到第 201 本及以后；需缩小筛选范围。
- “全部状态”包括已删除作品；后台查询没有默认排除已删除数据。

### 4.2 列表字段

| 列 | 展示及口径 |
| --- | --- |
| 相册 / 作者 | 相册名称可点击打开详情；下一行显示作者昵称与用户 ID |
| 页面 / 小卡 | 显示实际内页数与已占用卡位数 |
| 权限 | 公开 / 私密，对应用户设置的可见性 |
| 状态 | 草稿 / 已发布 / 已删除；存在运营限制时另显示“限制公开”标签 |
| 举报 | 目标为该数字相册的举报记录总数，未限定仅待处理举报 |
| 更新日期 | 作品更新时间，由公共表格按北京时间格式化显示 |
| 操作 | 查看；更多操作中提供限制公开或解除限制 |

计数规则：

- 页面数不包含封面，单面 / 双面阅读不额外生成或重复计算实际内页。
- 小卡数按内页中已填写小卡 ID 的卡位实例计算，重复放置同一卡会重复计数。
- 空卡位不计入小卡数；封面小卡不计入这项内页小卡数。
- 图鉴小卡后来不可用，原卡位引用仍可能被计数，详情用不可用占位显示。

### 4.3 作品详情

点击相册名称或“查看”，打开宽约 720px 的详情抽屉。

| 信息区 | 当前展示 |
| --- | --- |
| 基本信息 | 相册名称、作者昵称、简介 |
| 发布信息 | 公开 / 私密、作品状态、是否限制公开 |
| 系统信息 | 相册 ID、创建时间、更新时间 |
| 内页内容 | 按页面顺序展示“第 N 页”，逐个卡位展示小卡图片和名称 |

卡位显示规则：

1. 有小卡引用、图片地址可用且小卡可用：展示正面图片，完整适应卡位，不裁切主体。
2. 有小卡引用但资源不可用：展示“小卡暂不可用”。
3. 没有小卡引用：展示“空卡位”。
4. 图片下方显示小卡标题；标题不可获取时退回小卡 ID。

当前详情是只读查看，不提供后台替用户编辑卡位、修改作品文字或替用户发布的操作；也没有完整的封面与翻页效果预览、正背面交互预览或历史版本切换。

详情直接使用当前列表返回的作品对象，打开抽屉时没有再次查询最新详情。因此列表刷新前后的数据时效需要区分。

### 4.4 编辑版本与发布版本

系统同时保留用户当前编辑内容和上次发布快照：

| 视角 / 操作 | 使用的内容 |
| --- | --- |
| 作者编辑、后台管理查看 | 当前可编辑内容 |
| 其他用户访问已公开作品 | 最近一次已发布快照 |
| 作者继续保存编辑 | 更新编辑内容，不立即替换发布快照 |
| 作者再次发布 | 将当前内容写入新的发布快照 |

“已发布”只代表作品已有发布状态，不保证后台当前看到的每项编辑都已经对外展示。当前后台没有草稿与发布快照对比界面。

## 5. 限制公开与解除限制

### 5.1 限制公开流程

1. 有权限的运营人员在作品行选择“限制公开”。
2. 弹窗说明不会删除用户小卡和编辑数据。
3. 填写处理原因，必填，页面去除首尾空白；最多 200 字符。
4. 确认后保存运营限制标记，记录处理人、目标、前后值及原因。
5. 刷新列表，作品出现“限制公开”标签，操作切换为“解除限制”。

### 5.2 对 App 的影响

- 分享链接、他人访问及他人收藏引用中的公开访问被阻止。
- 作者仍可访问自己的作品并维护编辑数据。
- 作品状态和用户原设置的公开 / 私密属性不被直接改写；限制是独立标记。
- 受限制作品不能重新发布为可公开访问内容；不影响私密作品数据保留。
- 当前操作只记录处理结果和审计，不包含向作者自动发送站内消息或推送的完整链路。

### 5.3 解除限制流程

1. 选择“解除限制”。
2. 填写必填处理原因，最多 200 字符。
3. 确认后清除运营限制标记并记录审计。
4. 是否可被他人访问，仍取决于作品是否已发布、是否公开、作者账号是否可访问等条件。

解除限制不会自动将私密作品改为公开，也不会将草稿自动发布。

### 5.4 状态组合

| 作品状态 | 用户可见性 | 运营限制 | 他人是否可以访问 |
| --- | --- | --- | --- |
| 草稿 | 任意 | 任意 | 不可访问 |
| 已发布 | 私密 | 任意 | 不可访问 |
| 已发布 | 公开 | 否 | 作者账号正常等其他条件满足时可访问 |
| 已发布 | 公开 | 是 | 不可访问 |
| 已删除 | 任意 | 任意 | 不可访问 |

后台对已删除作品禁用限制 / 解除限制按钮，但仍可查看。当前接口仅判断记录存在，没有与前端完全相同的“已删除禁操作”校验，详见第 10 节。

## 6. 额度与会员

### 6.1 全局容量配置

| 字段 | 代码默认值 | 允许范围 | 生效对象 |
| --- | ---: | ---: | --- |
| 普通用户相册上限 | 10 本 | 1–100 | 普通用户可持有的非删除自建作品总数 |
| PRO 相册上限 | 30 本 | 1–100 | 有效 PRO 用户可持有的非删除自建作品总数 |
| 普通用户实际页面上限 | 10 页 | 1–50 | 普通用户每本卡册实际内页 |
| PRO 实际页面上限 | 20 页 | 1–50 | 有效 PRO 用户每本卡册实际内页 |
| 每页卡位上限 | 9 个 | 1–9 | 所有用户的页面布局卡位上限 |
| 公开内容拦截词 | 空列表 | 后台输入最多 4,000 字符；服务端最多 200 项 | 公开发布校验 |

规则：

- 五个数字字段必填，并作为整数范围校验。
- 配置是全局配置，当前没有分用户例外额度、按渠道配置或定时生效。
- 保存后，后续获取权益及执行新增操作使用新配置；已打开的 App 页面可能需要刷新额度，最终以服务端写入校验为准。
- 草稿、私密和已发布自建相册均计入相册数量；已删除相册不计。
- 收藏他人相册是引用关系，不按自己新建一本计入该容量。
- 当前不检查 PRO 上限必须高于或等于普通用户上限，管理员可以配置出 PRO 更小的值。

### 6.2 超额与到期保护

当降低额度或会员到期后，已有作品和超额页面保留：

- 仍可查看、编辑已有内容、排序及删除。
- 创建新相册时，按当前非删除作品总数和当前权益上限校验，已达上限则阻止。
- 增加实际内页时，校验当前页数上限；超过上限且比原有页数更多则阻止。
- 增加页面布局卡位时按当前全局上限校验；已有超限布局不因配置调小被自动裁剪。
- 不自动删除作品、不把超额页面移入回收站。

这些是容量保护规则；当前系统没有按会员限制取色次数、扫描次数或系统素材范围。

### 6.3 公开内容拦截词

配置方式：每行一个词，保存前去除每行首尾空白并过滤空行，未做去重。

校验对象：相册名称、简介、封面与内页中的文本元素。采用不区分大小写的包含匹配，不是复杂语义识别。

触发时机：

- 作者发布公开相册时，校验本次发布内容。
- 已发布作品从私密改为公开时，校验对外使用的已发布内容。
- 命中后阻止公开操作，提示“公开内容需修改后再发布”。

现有配置不会自动回溯扫描并下架所有历史公开作品，也不自动创建一条人工审核任务；私密保存和私密发布不使用这一公开校验。

### 6.4 用户会员授权

| 字段 | 必填 | 当前规则 |
| --- | --- | --- |
| 用户编号 | 是 | 手工输入用户 ID；服务端检查用户是否存在 |
| 会员类型 | 默认普通用户 | NORMAL 普通用户 / PRO |
| 到期时间 | 否 | 可选择日期和时间；为空表示不设置到期时间 |

操作流程：输入用户编号 → 选择类型和到期时间 → 更新权益 → 提示成功并清空授权表单。

生效规则：

- 选择 PRO，且未设置到期时间或到期时间晚于当前时间，按 PRO 权益计算。
- PRO 到期后按普通用户权益计算；原授权记录可以仍保留 PRO 类型，系统根据有效期判断实际权益。
- 选择普通用户后立即按普通权益计算，即使填了未来到期时间也不变为 PRO。
- 可以设置已过去的时间，此时 PRO 立即视为失效；当前没有“必须晚于现在”的限制。
- 同一用户更新覆盖当前类型和到期时间，不是追加会员天数，不自动延长原到期时间。
- 当前表单不先查询并回填该用户的已有权益，也没有本模块内的会员用户列表、订单或续费记录。

这是后台人工授权，尚未接入购买、支付、自动续费、退款和恢复购买；未设到期时间的 PRO 是无到期人工授权，不应对外描述为已售终身会员。

## 7. 主题与系统素材

### 7.1 素材类型及列表

| 类型 | 用途 | 当前数据形式 |
| --- | --- | --- |
| SHELF 书架 | App 书架外观 | 书架配色数组和层板颜色 |
| STICKER 系统贴纸 | 作品装饰 | 字符符号或简短文本 |
| BACKGROUND 背景 | 作品背景 | 纯色 / 渐变的颜色与角度配置 |

列表展示名称、资源 ID、类型、状态、排序、配置和编辑操作；展示上架与下架素材，按排序值升序排列，不分页。当前没有素材搜索、类型筛选或批量操作。

默认素材与数据库维护的素材合并展示。同一个 ID 的数据库记录覆盖同 ID 默认素材，因此默认素材也可以通过编辑记录修改或下架。

代码内置默认：5 个书架主题（奶油白、浅粉色、浅木色、银色金属、极简）、5 个符号贴纸（星光、热爱、蝴蝶结、花朵、陪伴）、3 个渐变背景（梦境、晴空、夜光）。实际内容以后台保存结果为准。

### 7.2 新增与编辑

点击“新增系统素材”或行内“编辑”，打开表单弹窗。

| 字段 | 必填 / 默认 | 后台表单规则 |
| --- | --- | --- |
| 资源 ID | 必填 | 1–40 个英文字母、数字、下划线或短横线；编辑时不可修改 |
| 名称 | 必填 | 最多 50 字符 |
| 类型 | 新增默认系统贴纸 | 书架 / 系统贴纸 / 背景 |
| 状态 | 新增默认上架 | 上架 / 下架 |
| 排序 | 新增默认 0 | 数字，按升序展示；服务端为整数，没有非负范围限制 |
| 配置 JSON | 必填 | 后台输入最多 8,000 字符；先检查 JSON 格式，再校验对应类型字段 |

新增默认配置为 `{"symbol":"✦"}`。切换类型不会自动改写 JSON 模板，操作人员需要填写对应类型的配置。

保存成功后关闭弹窗并刷新列表；JSON 格式错误提示“配置不是有效 JSON”，类型内容不合法则显示服务端校验信息。

当前保存按 ID 新增或更新：若新增时输入已经存在的 ID，会更新该 ID 对应资源，而非提示唯一性冲突。此行为需要运营人员留意。

### 7.3 配置要求与示例

**系统贴纸**

只允许一个 `symbol` 字段，值为 1–24 个字符的字符串；不接受图片 URL 配置。

```json
{"symbol":"✦"}
```

**书架**

只允许 `colors` 和 `ledge`；`colors` 为 2–4 个六位 HEX 颜色，`ledge` 为一个六位 HEX 颜色。

```json
{"colors":["#F4EEE7","#FFFFFF"],"ledge":"#DAD0C5"}
```

**背景**

`type` 为 `SOLID` 或 `GRADIENT`；颜色数组 1–4 项，渐变至少 2 项，每项使用 `#RRGGBB`；角度为 -360 至 360。省略类型时默认纯色，省略角度时默认 45。

```json
{"type":"SOLID","colors":["#F4EEE7"],"angle":45}
```

```json
{"type":"GRADIENT","colors":["#D7CEFF","#F9DEE9"],"angle":45}
```

当前素材采用配置 JSON，不包含图片上传、素材图片裁剪、文件存储、付费素材包、会员分档或版权授权管理字段。

### 7.4 上下架与 App 使用

- 上下架通过编辑弹窗的“状态”字段保存，没有独立的一键上下架按钮。
- App 素材接口仅返回上架资源，后台保留全部资源便于维护。
- 下架书架主题不能被新选择并保存为书架偏好；原偏好记录不会被自动清除。
- 新作品引用从未使用过的下架贴纸 ID 时，服务端拒绝。
- 已有作品的贴纸引用和布局保留；但当前校验按旧作品是否用过该资源 ID 判定，不能保证禁止在同一作品内复制该下架贴纸。
- App 整本复制相册时会保留原文档中的贴纸，包括下架贴纸；该复制流程没有重新运行素材可用性校验。
- 贴纸资源从 App 可用列表中消失后，内置贴纸有对应符号回退；自定义贴纸可能回退为默认星形，因此“保留布局”不等于保证原视觉完全不变。
- 背景在作品中保存颜色配置副本；下架背景预设不自动清除已保存的颜色，服务端也未按背景资源 ID 对任意相同颜色配置实施禁用。

## 10. 当前实现边界与待澄清点

以下为现有行为或差异，不作为已完成的增强能力描述：

1. **作品列表范围**：最多取按更新时间倒序的 200 本，分页总数只是本次返回数量，没有服务端全量分页和总数。
2. **后台所见版本**：详情来自当前编辑内容及列表缓存，没有访客发布版本切换、差异对比或打开详情时重新拉取。
3. **已删除作品操作**：前端禁用限制公开，但后端对应接口未禁止修改已删除作品限制标记。
4. **限制原因格式**：前端去空格后检查非空；后端仅校验字符串长度，未同样去除纯空白。
5. **配置关系**：没有校验 PRO 容量应大于普通用户；降低配置也没有受影响用户预览或二次汇总确认。
6. **会员管理范围**：仅按用户 ID 直接覆盖权益，没有先查后改、批量授权、会员订单、自动续费和退款同步。
7. **素材字段长度**：页面资源 ID 1–40、名称最多 50；服务端 ID 上限 64、名称上限 80，直接调用接口可写入页面新增规则之外的数据。
8. **素材 ID 重复**：新增和编辑共用按 ID 保存能力，没有防止新增误覆盖现有 ID；编辑时也未锁定素材类型。
9. **下架素材保护**：已有贴纸按资源 ID 放行，同作品复用、整本复制和自定义符号回退存在上述边界；不应写成全面禁止新增实例且完全保真。
10. **日期时区**：列表按北京时间展示，但筛选条件提交不含时区偏移，服务端直接解析；跨时区边界仍需专项验收。
11. **内容复核范围**：拦截词不是图片识别审核；配置变更不自动追溯历史作品；作品限制不自动关闭举报或发送消息。
12. **付费体系范围**：本模块没有扫描额度、取色计次、PRO 专属素材、订阅支付及收益看板。相关讨论见独立会员需求稿。
13. **公开限制作用范围**：限制作用于当前作品 ID；App 复制作品生成新的私密草稿时不继承原限制标记，不能据此认为副本已受同样限制。
14. **配置整体保存**：额度接口保存整份配置，直接调用时省略的字段会采用默认值；当前页面提交完整表单，未提供局部配置变更模式。
