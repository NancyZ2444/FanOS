## 图鉴业务规则

小卡录入顺序：选择组合 → 选择艺人 → 选择来源 → 基础信息 → 正反面图片 → 标签属性 → App 预览 → 审核发布。保存草稿只要求基础名称和有效归属，允许逐步补齐；提交或发布需要完整校验。

| 动作 | 原状态 | 结果 |
| --- | --- | --- |
| 保存新建／编辑 | 草稿、驳回或下架 | 草稿 `DRAFT` |
| 提交审核 | `DRAFT` / `REJECTED` / `OFFLINE` | `PENDING` |
| 审核发布 | `PENDING` | `PUBLISHED` |
| 驳回并填写原因 | `PENDING` | `REJECTED` |
| 下架 | `PUBLISHED` | `OFFLINE` |
| 归档 | `DRAFT` / `REJECTED` / `OFFLINE` | `ARCHIVED` |
| 恢复 | `ARCHIVED` | `DRAFT` |

已发布或待审核的小卡不能直接改内容；下架或驳回后再修改。更新提交 `expected_updated_at` 检查并发版本，冲突返回 409。批量状态操作在单个事务中执行，一条失败则整批回滚。提交失败但已保存的草稿保留在原 ID 下，可继续修正。

提交／发布时检查：

- 艺人与来源对象存在，上游已发布；组合归属检查使用发行时的历史有效期，Solo / 合作来源通过参与艺人 ID 校验。
- 个人卡必须选艺人；团卡允许 `idol_id` 为空。
- 正面图片必填；双面卡须有背面；AR 卡须有资源地址。
- 每张实际提供的正反面图片分别填写来源链接，版权状态为 `AUTHORIZED` 或 `OFFICIAL_SOURCE`。
- 校验错误返回具体字段，页面跳到对应步骤；导入错误包含行号、字段与修复建议。

来源与版权详情仅由后台接口返回，公开小卡序列化使用字段白名单。App 图鉴仅返回已发布内容；AI 扫描候选允许 `PUBLISHED` 和 `OFFLINE`，过滤草稿等未审核小卡。团卡公开 API 的空艺人 ID 兼容现有 Flutter 字符串模型，点击归属跳转组合。
