## 页面与功能变更

| 页面 | 本次修改 |
| --- | --- |
| 小卡列表、新增、上传识别 | 上传识别与 App 共用当前人物检测、几何候选、边缘精修及匹配状态判断；多张时默认不选中，明确选择一张后才可裁剪识别；可手动调整四角。近似匹配仍需人工确认。 |
| 图鉴反馈导航 | 仅保留「图鉴新增」「图鉴信息错误」。前者合并当前 App 的缺失小卡及其他实体新增申请；旧页面地址兼容到合并入口。 |
| 艺人、组合资料 | 复用纵向标签及双列表单，回填正式资料；保存草稿与预览发布分开；发布前查看变更，取消或离开时保护未保存输入。 |
| 艺人、组合关联内容 | 小卡列展示可点击缩略图；成员及所属组合名称可跳转详情。 |
| 图鉴新增、纠错详情 | 继续使用统一反馈闭环；精简录入与处理区域，原始提交及历史可展开，时间明确为北京时间。内部草稿不更新用户动态。 |
| 公司管理 | 「开启 / 未开启」替代公司发布状态与有效期。未开启公司不能建立新归属；历史归属保留。公司经历的开始/结束日期仍作为业务历史保留。 |
| 组合、艺人新增与导入 | 公司选择使用后台正式公司列表，新增且尚未关联内容的公司也可选。未知公司按名称标准化匹配，未存在时自动创建且默认开启；已有未开启公司不会被导入重新开启或重复创建。 |
| 小卡、实体、反馈、资料及导入 | 移除图片出处、来源链接、版权声明等人工录入与发布必填检查。旧文件解析仍兼容；新模板不再包含这些列。现有来源元数据保留，不自动标记为已授权。 |
| 明星动态表单 | 移除原始链接录入；编辑时未提供该字段不会覆盖已存原始链接。 |
| 角色与权限 | 权限矩阵支持勾选、取消、保存和版本冲突提示；API 每次请求校验最新权限，页面导航与操作按钮同步使用权限配置。超级管理员保留完整权限。 |
| App 登录客服入口 | 分组表单与公开内容预览，统一控件尺寸、保存、取消及未保存保护。 |

专辑 / 活动 / Other 是小卡的业务关联，继续保留并校验；本次移除的是图片出处和版权录入。小卡图片、所属组合/艺人、发行来源、版本、双面卡背面和 AR 素材等原有必要校验仍生效。

公共 UI 继续使用项目已有设计变量和组件。新增样式集中在 `catalog-editorial.css`；公共原生日期输入框统一为 36px。检查宽度为 1280、1440、1920 CSS px。

## 接口与数据处理

- 新增 `/admin/console/feedback?kind=ADDITIONS`，同时返回 `MISSING_CARD` 与 `MISSING_CATALOG`；`CORRECTION` 仍为独立队列。
- 当前 App 扫描未匹配结果经 `MissingCardFeedbackPage → POST /feedback` 提交；旧扫描反馈页面已无入口。退役旧 `/catalog/feedback`、`POST /scan/feedback` 以及旧后台 `/review-queue`、`/quality` 路由。
- 公司开关保存为公司记录中的 `data.enabled`，无需重建实体 ID 或业务表。没有该字段的旧公司以非下架/归档视为开启，保留既有状态供历史追溯。
- 角色权限使用现有版本化状态表保存，无需重建账号。接口拒绝过期版本覆盖和越权请求；保存后后续 API 请求即生效，其他账号刷新页面后更新导航。勾选账号管理、敏感信息或身份解绑时自动勾选账号查看；测试验证码配置依赖登录白名单入口。
- 仅有图鉴发布权限也能完成当前反馈的审核发布；临时写入授权只覆盖本次反馈事务、当前处理人和对应实体，不授予普通新增或草稿编辑权限。相册素材/权益管理与作品内容审核分别校验权限。
