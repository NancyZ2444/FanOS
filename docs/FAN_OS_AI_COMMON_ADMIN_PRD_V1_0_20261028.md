# Fan OS AI 通用建设与后台配置 PRD V1.0

| 项目 | 内容 |
| --- | --- |
| 日期 / 状态 | 2026-10-28 / 待评审 |
| 目标 | 为 Live 小卡和快速找图建立可复用、可追溯的 AI 配置与管理能力 |
| 管理原则 | 研发维护技术配置；运营维护效果展示和业务开关 |
| 范围 | 后台公共配置及两项业务接入；不代表功能已实现 |

## 1. 背景与目标

Live 小卡依赖图生视频及异步处理，快速找图依赖描述理解、图文编码、向量索引和可选候选核对。两者需共用供应商、模型能力、凭证引用、路由、预算、限流、发布及审计，但不能把不同能力、任务或权益合并为同一配置。

目标：新 AI 场景能够复用通用接入和管理；运营可在经过研发验证的范围内管理效果和开关；配置可校验、发布、追溯及回滚，故障时不影响已有作品和普通搜索。

## 2. 范围与角色

| 模块 | 本期内容 | 负责人 |
| --- | --- | --- |
| AI 服务 | 供应商、能力、模型版本、凭证引用、连接测试 | 研发 |
| 场景配置 | 路由、提示模板、参数、超时、重试、降级、灰度、预算与限流 | 研发 |
| 发布与监控 | 版本、校验、发布、回滚、调用与成本、审计 | 研发；运营按授权只读 |
| Live 效果 | 效果名称、介绍、示例、排序、启停；关联已验证技术方案 | 运营 |
| 业务开关 | Live、快速找图和已开放效果的启停 | 运营；研发维护技术总开关 |

不在本文实现用户额度与支付、作品审核、源卡授权管理、找图索引批次及质量反馈的完整业务后台；分别遵循业务 PRD。本期不提供运营编辑提示词、模型参数、供应商或密钥的能力。角色基于现有后台权限体系扩展，页面隐藏与服务端鉴权均须生效；具体账号分配由管理员维护。

## 4. 核心对象与配置

### 4.1 供应商与凭证

列表展示名称、环境、状态、凭证引用、最近连通测试及更新时间。研发可新增、编辑、停用及测试；凭证由服务端秘密管理系统或部署配置维护，后台只保存引用和脱敏状态，不显示或回填密钥。测试只验证指定能力的连通性，显示时间、结果及可能费用；不代表效果、授权或上线验收通过。停用前展示引用场景及影响，已接受任务按原快照处理。

### 4.2 模型能力

按供应商维护能力类型、模型及接口版本、适配器版本、输入输出约束、地域、用量单位、可用状态和验证记录。首期覆盖图生视频、文本理解、文本编码、图片编码、可选候选核对；媒体封装不视为模型。支持登记供应商数据使用约定和真人图片处理许可的验证结论及证据链接；未经验证不可用于生产路由。模型能力是技术登记，不向 App 暴露供应商选择。

### 4.3 场景、路由与模板

| 场景 | 主要配置 | 必须满足 |
| --- | --- | --- |
| Live 生成 | 图生视频主路由、已验证备用路由、提示模板、输入约束、输出档位、队列及处理策略 | 备用路由与效果和交付档位均通过验收；未知提交状态先核对，不盲目切换 |
| 快速找图 | 理解、文本／图片编码、向量空间、检索与可选核对配置 | 文本和图片编码器、预处理与索引空间版本兼容；切换前完成对应索引准备 |

每个场景支持草稿编辑、校验和版本比较。提示模板由研发维护，包含变量定义、约束、版本及适用范围；保存前校验必需变量与格式。Live 效果只关联研发已发布、已验证的技术方案，运营不能改写其内容。找图可选核对、OCR 等技术增强开关由研发维护，默认遵循业务 PRD；不与运营的功能总开关混同。

### 4.4 提示词管理页面（研发）

研发通过后台界面维护提示词模板，无需每次修改代码或部署。列表支持按名称、场景、能力、状态和版本筛选，展示模板名称、用途、当前发布版本、关联场景、最近修改人及时间；可查看详情、新建草稿、复制版本、编辑、校验、发布和回滚。运营无查看或编辑提示词内容的权限，接口同样鉴权。

| 字段 | 维护要求 |
| --- | --- |
| 模板名称、用途、场景及能力 | 必填；场景和能力决定可关联的路由与校验规则 |
| 提示词内容 | 多行编辑；支持按适配器定义的角色或分段，原样保存，不将用户输入作为系统配置执行 |
| 变量 | 声明变量名、含义、类型、是否必填及示例；变量由服务端按白名单填充，不允许任意执行代码 |
| 约束与输出格式 | 维护内容约束及结构化输出要求；由对应能力的适配器校验 |
| 版本说明、关联方案 | 填写修改原因，展示关联场景、Live 技术方案及影响范围 |

操作流程：研发新建或复制草稿，填写内容和变量，保存后进行变量、格式和能力兼容校验；可使用经授权的测试样本试运行，界面先展示可能产生调用费用，再显示结果、耗时、错误及关联模型版本。测试不修改正式图鉴、不触发用户权益结算，也不自动发布；测试样本与结果遵循数据权限和留存规则。发布前展示内容差异、关联对象及影响，确认后生成不可变版本。提示词发布与场景配置发布可分开，但只有场景或技术方案引用并发布了该提示词版本后，新请求才使用它；已有请求保持原快照。回滚通过复制历史版本为新版本并重新校验、发布，再更新场景引用完成，不直接改写历史。

避免在提示词中填写密钥、个人信息或生产用户原文；界面提供明确提示，服务端仍需执行权限和数据保护校验。提示词属于技术配置，不将其暴露给 App 或运营，也不允许模型输出修改后台配置。

### 4.5 预算、限流和降级

研发按环境、场景及阶段配置日／月预算、告警阈值、并发、频率、超时、重试上限与降级策略。金额、币种、统计时区及周期在配置中明确，估算与供应商账单区分展示；预算因计量延迟可能短暂超限，不能作为精确财务账单。建议优先预留已接受 Live 任务的后处理预算。触及硬上限时停止接收对应新付费调用；找图优先暂停历史建库和可选增强，再按业务规则降级到普通搜索，核心失败不扣用户次数。Live 已接受任务继续按原承诺处理，不能因关闭入口直接扣次或丢弃。

## 5. 运营页面与操作

### 5.1 功能开关

列表展示功能名称、运营开关、技术状态、实际状态、影响说明、最后修改人和时间。实际可用需同时满足运营开启、研发技术开关开启、已发布配置有效及预算／依赖允许；显示具体不可用原因。开启前校验依赖，失败时说明原因并保持关闭；关闭时二次确认影响及填写原因。

| 功能关闭 | 对新请求 | 对已有数据／任务 |
| --- | --- | --- |
| Live 小卡 | 停止新生成，入口显示暂不可用；不预占额度 | 已接受任务继续恢复及交付，已有作品仍按权限访问 |
| 快速找图 | 停止新 AI 分析，保留普通搜索 | 保留历史及既有请求状态；已接受请求按原规则结算或释放，不能静默新增请求 |
| 单个 Live 效果 | 不再用于新任务 | 已提交任务按原效果版本执行，旧作品保留 |

开启不自动恢复被研发关闭、预算限制或故障熔断的技术服务。开关只对服务端确认后的新请求生效；对于确认页已展示但尚未提交的请求，提交时重新检查并提示，若承诺规格或消耗变化须重新确认。

### 5.2 Live 效果管理

列表提供搜索、状态筛选、排序、创建、编辑和启停；展示效果名称、示例、关联技术方案版本、适用范围摘要、状态与更新时间。详情字段：名称、简短描述、示例封面／视频、展示排序、技术方案选择、启停状态。示例明确标注“效果示例”。上传文件应校验类型、大小及可播放性，具体限制由研发配置并在页面提示。

运营可编辑展示信息，选择研发已发布且标记可运营使用的方案；不可自定义提示词或更改模型。启用前校验示例、方案、功能状态和兼容性；方案失效时效果自动不可用于新任务并显示原因。变更发布形成效果版本；生成任务保存效果与技术方案版本快照。删除仅允许从未使用的草稿；已使用效果只能停用，保留历史引用。

## 6. 发布、回滚与一致性

1. 研发创建草稿并修改；保存不影响线上。页面展示字段差异、关联场景和预计影响。
2. 发布前校验必填、权限、凭证引用、能力与模板兼容、预算及场景特有依赖；连通测试和效果评测结果独立展示。未通过硬校验不能发布。
3. 生产发布需填写原因并确认影响；采用已有后台权限控制，首期不强制新增审批流。每次发布生成不可变版本、操作者、时间与审计记录。
4. 生效版本供新请求读取；请求创建时固定所需配置快照，不能因后续发布改变已承诺交付、用户计次或处理中任务。
5. 回滚是将历史配置复制为新版本并重新校验发布，保留完整历史。找图必须同时确认编码器与索引空间兼容；旧空间不可用时禁止直接回滚，显示阻塞原因。回滚不撤销已创建任务、账本或作品。
6. 并发编辑采用版本号检查；版本已变化时拒绝覆盖并要求刷新比较。配置读取异常使用最近有效版本或按场景安全停接，不能使用部分新旧配置拼接。

## 7. 监控、审计与权限

调用记录按时间、场景、能力、配置版本、供应商、状态、请求／任务 ID 筛选，展示尝试次数、耗时、用量、估算费用和错误分类。统计真实供应商尝试，与用户次数分开；支持按场景、阶段和版本汇总成功率、延迟与成本。日志不记录密钥、完整签名链接或不必要的原图和用户原文；原文访问及留存遵循业务数据规则。

审计记录创建、修改、测试、发布、回滚和开关操作，含对象、前后版本、操作者、时间、原因、结果及请求 ID；敏感值仅记录引用和变更状态。审计不可由普通运营或研发通过业务页面删除。

| 权限 | 研发 | 运营 |
| --- | --- | --- |
| 技术配置查看、编辑、测试、发布、回滚 | 授权后允许 | 无 |
| 效果展示配置和业务开关 | 按授权 | 按授权 |
| 调用与成本汇总 | 授权后可查看 | 按授权只读汇总，不默认查看原始内容 |
| 密钥明文 | 后台不可查看；通过秘密管理系统授权维护 | 无 |

## 8. 验收标准

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| A01 | 运营调用技术配置写接口 | 服务端拒绝，记录越权事件 |
| A02 | 研发配置凭证及测试 | 页面无明文；测试与生产验收状态分开 |
| A03 | 不兼容模型、模板或缺失依赖发布 | 明确指出问题，线上版本不变 |
| A04 | 运营启用未验证效果 | 阻止启用并说明原因 |
| A05 | 编辑展示内容、排序和停用效果 | 新请求使用新版本，历史任务和作品不变 |
| A06 | 关闭 Live／找图 | 新请求按第 5 节受控；已有任务、作品和普通搜索行为符合约定 |
| A07 | 技术总开关关闭时运营开启 | 页面展示实际不可用及原因，不能绕过技术限制 |
| A08 | Live 提交状态未知 | 不盲目切换供应商或重复扣次，进入核对流程 |
| A09 | 找图模型切换或回滚 | 编码器与索引空间匹配；不兼容则阻止发布 |
| A10 | 预算耗尽 | 按场景停接或降级，用户权益按业务规则处理 |
| A11 | 并发编辑、重复发布、回滚 | 冲突不覆盖；操作可追溯，旧任务快照不变 |
| A12 | 监控与审计 | 可按任务追溯版本、实际尝试和成本；无密钥泄漏 |
| A13 | 研发界面编辑、测试及发布提示词 | 变量和格式校验生效；测试不扣用户权益；版本和操作可追溯 |
| A14 | 提示词发布与场景关联 | 未更新场景引用时线上行为不变；更新后仅新请求使用新版本，旧请求保留快照 |
| A15 | 运营访问提示词页面或接口 | 无权查看内容或修改，服务端拒绝越权访问 |

## 9. 交付与待定事项

建议先交付服务登记、权限、版本发布、场景路由、预算及审计，再接入找图与 Live，最后开放运营效果管理与开关。每项功能需通过各自业务 PRD 的效果、权限、成本与交付验收后才开放生产；技术配置完成不等于业务已上线。

实施前确定：供应商及模型、秘密管理方式、实际预算与阈值、评测和连通测试费用、告警接收方式、日志及备份保留周期、运营具体授权范围、灰度对象与放量门槛。本文不预设尚未验证的模型或生产参数。
