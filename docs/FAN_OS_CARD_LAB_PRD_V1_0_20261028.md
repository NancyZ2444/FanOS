## 1. 目标与范围

用户从系统图鉴选择小卡，通过镭射、边框和装饰物创作多个可保存的装扮作品。作品支持私密或公开；用户可为每张小卡指定一个自己的作品，作为已拥有和心愿单的装扮展示。减少编辑过程中的提示文案，让卡面预览成为视觉中心。

一期开放创作、保存、管理、独立隐私、会员限制和收藏列表装扮模式。二期支持分享到社区、将装扮快照加入卡册。图鉴原图、已拥有数量、心愿关系和卡册原有模式不因创作改变。

已确认：任意系统图鉴小卡可创作，包括未加入收藏的卡；一张卡可保存多个作品；每张卡至多指定一个作品作为装扮，可取消；默认私密；已拥有和心愿单的装扮模式只使用用户自己的指定装扮，未指定则显示原卡；二期卡册保存加入时快照。

## 2. 信息架构与流程

- 收藏 → 作品：固定为「卡册｜小卡实验｜Live小卡」，将原「砖卡」占位改名并启用。小卡实验为独立作品类型，独立计数及额度；卡册的 BOOK／CARDS 模式不迁移。本人、访客主页及作品收藏分类同步更名。
- 作品 → 小卡实验 → 新建 → 选择图鉴小卡 → 编辑 → 保存作品。图鉴小卡详情提供「小卡实验」入口，带入当前卡；已拥有／心愿单小卡详情可进入该卡的实验结果。
- 我的小卡实验先按图鉴原卡分组展示；点击原卡进入该卡的实验结果列表，再选择具体样式进入大图预览。作品管理与设为装扮操作见 2.1、2.2 节。
- 保存成功后留在结果页，可选择设为装扮；保存作品本身不自动改变当前装扮。作品名称建议自动生成并允许修改，避免阻断创作。

### 2.1 按原卡聚合与实验结果列表

| 层级 | 展示与操作 |
| --- | --- |
| 第一级：原卡列表 | 每张有至少一件可见实验作品的图鉴小卡显示一项，使用图鉴原卡缩略图、基础识别信息及该卡可见实验作品数；同一原卡不因多个样式重复出现。本人可新建；点击原卡进入第二级。建议按组内作品最近修改时间倒序，搜索按原卡信息匹配。 |
| 第二级：该卡的实验结果 | 顶部显示原卡及基础信息，下面逐件展示装扮后的静态缩略图、作品名称；本人可见每件公开／私密状态及「当前装扮」标记，点击某件进入该件大图预览。建议按作品最近修改时间倒序，并提供基于当前原卡的新建入口。 |
| 第三级：作品预览 | 聚焦所选作品，支持大图和反光交互；本人可从此进入编辑、公开设置、删除或设为／取消装扮。也可在结果列表的作品操作菜单提供同样操作。 |

例：原卡 A 有实验作品 A1、A2、A3，第一级仅展示一张 A 原卡并标注 3；点击后显示 A1、A2、A3 的不同效果，点击 A2 进入 A2 的预览。选择 A2 为装扮后，两处收藏列表在装扮模式显示 A2，但第一级仍显示原卡 A。

Tab 数量继续表示作品总数而非原卡组数；一级每组数字为该组可见作品数。本人按未删除且本人可读取的作品计算；访客仅按有权访问的公开作品计算，不能显示私密作品数，也不能显示仅有私密作品的原卡分组。作品收藏按当前收藏范围及类型、分组和可见性先过滤，再按「作者＋图鉴卡」聚合，避免将不同作者作品误认为同一人的实验；一级显示作者信息。自己创作与收藏内容各自计算，不混排。筛选、分页和数量由服务端按同一视角计算；加载失败显示重试，不伪装成空列表。

从图鉴详情及已拥有／心愿单进入时直接定位本人该卡第二级；无作品时显示简洁空状态和新建操作。从作品列表返回保留原卡列表滚动及筛选；预览返回保留结果列表位置及所选作品。删除该卡最后一件作品后本人原卡组移除；从图鉴进入时仍可新建。

作品收藏中的失效引用按现有通用收藏规则保留为本人可移除的不可访问占位，不展示原卡、作品缩略图或作者等缓存信息，也不并入可见原卡组；访客不展示失效占位。收藏 Tab 总数包含本人可管理的失效引用，因此可能大于可见分组内作品数之和。

### 2.2 小卡实验预览模式

参考卡册卡片模式的放大展示，但列表及预览对象为同一原卡的不同实验作品。结果列表点击某个作品后，以该作品为焦点进入预览：当前卡居中、其他可见样式在两侧缩小叠放；左右滑动或点击侧卡切换焦点。点击或抽出中央卡进入大图查看，保持完整比例，支持卡面拖动改变光线、回正和自动转动；手机倾斜需主动开启，失败仍可拖动。预览动画期间避免重复操作造成焦点错乱，低性能设备可降级为静态预览并保留切换。

大图默认正面，支持查看图鉴已有背面；建议装扮仅作用于正面，背面展示原图，未有背面时提示「暂无背面图片」，不生成空白假背面。可进入图鉴详情，返回恢复当前作品和查看位置；收回或关闭大图回到原焦点，退出预览返回原结果列表。查看大图与切换样式不创建作品、不占额度、不改变当前装扮。访客仅有阅读及符合权限的收藏操作，没有编辑、隐私、删除和设为本人装扮的操作。

仅有一个可见样式时居中展示该作品，不显示虚构的侧卡；从大图返回后保留当前焦点。列表页用静态缩略图，进入预览后才启动动态效果，退出或进入后台时暂停渲染。

编辑器内「预览」读取当前未保存内容，退出后回到原编辑位置和状态，不发布、不覆盖已保存版本；从结果列表或访客主页进入则读取相应已保存且有权访问的版本。加载失败、作品变私密／删除／下架时停止访问并提示，不显示失效缓存。正式预览不显示选框或编辑手柄。

## 3. 编辑器

原型采用小卡实时预览，功能如下；实际 App 应适配屏幕与手势，不要求复刻原型网页装饰文案。原型图片为示例图，正式使用选定的系统图鉴图片。默认图片比例应保持，长宽差异不得拉伸；渲染区域及裁切规则需在设计验收中覆盖各类图鉴比例。

| 功能 | 需求 |
| --- | --- |
| 镭射 | 单选工艺并实时预览；首批参考原型的彩虹细纹、碎钻银箔、星点闪膜、花纹镭射、边框金箔、珍珠柔光、爱心、五角星、菱形、星心混合、圆环，共 11 种；反光强度与纹理密度各 0–100%，默认分别 55%、50%。 |
| 柔化面部反光 | 开关，默认开启；原型是固定手工椭圆区域，不是自动人脸识别。应避免暗示精准识别，按实际效果展示。 |
| 边框 | 单选一款或无边框；支持边框整体位于装饰物上方或下方。原型含 6 款，正式素材以后台上架为准。 |
| 装饰物 | 可多次添加、选中、拖动、双指缩放和旋转，也可使用选框手柄缩放旋转；删除选中项。后添加的装饰覆盖先添加项；限定在卡面内呈现。原型含 10 款，正式素材以后台上架为准。 |
| 预览 | 拖动小卡改变角度和反光，支持回正、自动转动、主动开启／关闭手机倾斜；不支持或未授权传感器时仍可拖动。进入装饰编辑时卡片回正，手势优先编辑装饰。 |
| 对比 | 按住查看图鉴原图，隐藏镭射、边框及装饰；松开或触摸中断后恢复完整装扮。原型实际只隐藏镭射，本需求以完整原图对比为准。 |

原型默认开启一款镭射；建议提供「无镭射」以便只使用边框或装饰。图像、素材加载失败应保留已编辑内容并允许重试；离开未保存编辑时只在存在未保存修改时提示。常态界面保留必要的控制名称和数值，手势说明收纳为简短帮助，权限或失败仅在发生时提示，不重复堆叠提醒。

## 4. 保存、装扮与展示

1. 保存时服务端验证图鉴卡可用、作品额度、素材权益；成功后记录独立作品 ID、作者、图鉴卡 ID、可编辑配置、素材版本、可见性和预览。失败保留编辑状态，重试不重复创建。每个已保存作品占一个小卡实验额度；仅预览不占额度。
2. 建议编辑现有作品时保留已保存版本直至再次保存成功；保存后本人指定装扮展示最新保存版本。公开作品的访客展示也以成功保存版本为准，编辑中未保存内容不可见。
3. 对一张图鉴卡设置装扮时，原先指定的作品被替换；取消装扮解除关联而不删除作品。该映射按用户＋图鉴卡唯一，已拥有及心愿单共用，切换或移除其中任一关系不删除作品或映射。操作完成后两处刷新一致。
4. 已拥有、心愿单各提供「装扮模式／普通模式」切换。普通模式显示图鉴原卡；装扮模式优先显示本人指定作品，无可用装扮回退原卡。建议各列表记住用户上次选择，首次默认装扮模式。列表缩略图使用静态预览，详情可交互查看反光，避免列表大量实时渲染。
5. 删除被指定的作品时，在删除确认中说明会取消装扮；删除成功后回退原卡。保存失败、图片失效或权限异常不能用旧图冒充当前有效结果。装扮显示只改变视觉，不更改图鉴卡 ID、拥有数量、筛选统计或心愿状态。

## 5. 公开、访问与收藏

每个作品单独设置公开／私密，默认私密；沿用作品模块的本人、访客分离，卡册公开开关不控制小卡实验。建议公开作品在作者主页小卡实验 Tab 展示；访客仅可访问存在、已保存、公开且运营允许展示的作品，数量与实际可见列表一致。私密作品仅作者可访问和管理；变私密、删除、下架或限制公开后，列表、详情、收藏、链接与缓存均执行同一权限检查。

作品收藏沿用通用作品收藏：仅可收藏他人可访问的公开作品，不增加本人创作额度或图鉴拥有数量；原作品不可访问时，收藏者本人保留可移除的失效引用，访客不展示。用户自己的私密装扮可用于本人已拥有／心愿单，但不能由访客借该展示路径访问私密作品；访客查看收藏列表时建议对私密或不可访问装扮回退原卡。是否公开作品与是否设为本人装扮互不改变。

## 6. 会员与额度

在现有 NORMAL／PRO 权益体系中增加独立「小卡实验作品数量」和素材权限，后台可配置。以下为评审建议，不代表现行权益：

| 权益 | 普通用户建议 | PRO 建议 |
| --- | --- | --- |
| 已保存作品数量 | 10 件 | 50 件 |
| 素材 | 免费工艺、边框、装饰 | 免费及 PRO 素材 |
| 预览 | 可试用全部素材 | 可使用全部已授权素材 |

额度统计未删除的本人已保存作品，含私密、公开及受限作品；同一小卡多个作品分别计数。删除释放额度；切换装扮、编辑已有作品、收藏他人作品不增加作品数。到达额度时可查看、编辑或删除已有作品，但不可新增；入口只在需要时显示额度和权益说明。预览 PRO 素材不代表有保存权限，保存时给出清晰原因及处理入口；如支付尚未接入，只展示已存在的权益说明或授权入口，不伪造支付流程。

会员到期或额度降低时保留全部作品和已有视觉、公开状态与装扮映射；超额时禁止新增。已有 PRO 素材可保留、移动、缩放、删除，但不可新增或复制无权素材实例；重新获得权益后恢复。服务端以当前有效权益和素材实例差异校验，不能依赖前端锁定。后台调整权益须展示影响范围并保留操作记录。

## 7. 二期：社区与卡册

| 能力 | 需求边界 |
| --- | --- |
| 分享到社区 | 在作品结果页发起，以用户主动操作为前提；仅可分享当前可公开访问的已保存作品。社区帖子、审核、举报和作品后续私密／删除时的处理需与社区规则联动，二期细化；一期不出现不可用按钮。 |
| 加入卡册 | 从本人已保存作品选择，加入时保存卡面与装扮配置的快照；之后编辑、取消装扮或删除来源作品不自动改变卡册快照。沿用卡册容量及编辑规则；素材与图鉴图片失去展示授权时仍须遵守强制撤图要求。二期明确快照的动态渲染与静态降级、素材版本及卡册访问规则。 |

## 8. 后台、数据与影响点

| 影响区域 | 需求 |

| 作品与主页 | 更名、独立列表与权限计数、作品类型标识、通用收藏筛选、公开访问及失效处理；旧客户端对新类型安全降级。 |
| 已拥有／心愿单 | 新增模式和用户—卡片—作品映射；与已有数量、搜索、筛选、排序、操作及权限隔离；跨端同步并处理缓存失效。 |
| 素材后台 | 新增小卡实验专属镭射卡膜、边框管理；贴纸允许与卡册共用底层素材，但各场景单独配置与上架。具体规则见 8.1 节。 |
| 运营与审核 | 作品列表、详情预览、作者、关联卡、可见性、状态、举报、限制公开／下架／恢复及操作日志；限制或恢复须同步访问权限与缓存。 |
| 权益 | 独立额度与素材权限配置、用户授权、有效期和审计；不借用卡册额度。 |
| 渲染与存储 | 保存工艺及参数、面部柔化开关、边框层级、装饰的素材版本与位置／缩放／角度／顺序、静态封面和渲染版本；跨端兼容、失败重试及低性能降级。 |
| 安全与隐私 | 服务端验证所有权、图鉴与素材授权、作品状态；公开预览与私密缓存隔离，旧链接不能绕过权限。 |
| 数据统计 | 记录进入、选卡、保存成功／失败、设置／取消装扮、模式切换、额度触达、公开及二期转化；区分用户和作品，不采集不必要的图片内容。 |

作品类型和旧「砖卡」占位的映射需兼容已发布接口；该占位原无实际作品，不应转换卡册 CARDS 数据。先部署兼容服务及后台配置，再开放客户端入口；灰度和回退应保留作品数据与用户映射，不使旧版本误读新类型。

### 8.1 管理后台新增与更新

后台在「作品管理」增加小卡实验作品分类，增加「小卡实验素材」入口，分别管理镭射卡膜、边框及贴纸；卡册原有书架、封面、内页、卡片背景场景保持独立。三个素材分类分别提供列表、筛选、新增、编辑、预览和状态操作；列表至少展示名称、ID、预览、状态、会员范围、排序、更新时间及操作人。可按名称／ID、状态和会员范围筛选，排序仅作用于本场景本分类。

| 分类 | 管理与 App 落点 |
| --- | --- |
| 镭射卡膜 | 小卡实验专用，管理名称、唯一 ID、工艺类型／效果参数及渲染版本、预览、会员范围、排序和状态；预览需使用示例小卡、调整反光强度和密度并改变角度检查效果。仅进入小卡实验的镭射选择器，不与卡册素材共用。 |
| 边框 | 小卡实验专用，管理名称、唯一 ID、透明资源、预览、会员范围、排序和状态；预览需检查小卡适配及边框在贴纸上／下的效果。仅进入小卡实验边框选择器，不与卡册素材共用。 |
| 贴纸 | 可选择已存在的卡册贴纸资源或新增贴纸资源；在小卡实验建立独立场景条目，配置名称、预览、会员范围、排序和状态，并在小卡卡面检查透明度及缩放。共用底层文件或素材资源，不等于自动跨场景发布。 |

贴纸沿用卡册既有的场景独立管理原则：同一资源可由卡册和小卡实验各自条目引用，条目 ID、状态、排序和会员范围独立；修改或下架某一场景条目不改变其他场景及历史作品。将原卡册贴纸引入小卡实验时默认草稿，需在小卡实验预览并单独上架；只有格式、授权和端侧支持均符合时才能启用。资源文件替换采用新版本，既有作品保留原版本；因授权撤图等强制禁用底层资源时，所有引用场景一并停止展示并清理缓存。镭射和边框不建立卡册复用入口或跨场景授权。

素材状态建议沿用卡册的草稿 DRAFT、上架 PUBLISHED、下架 OFFLINE：草稿仅后台可见；上架后进入对应 App 选择器并按会员范围与锁定预览规则校验；下架后禁止新增使用，历史作品与已有实例按会员规则保留视觉。曾上架素材不能退回草稿；仅从未上架且从未使用的草稿允许删除，内置素材不可删除。上架前检查必填项、资源可用性、授权、场景、端侧支持及预览；操作确认展示影响场景及历史作品处理。素材被禁用、历史版本缺失或加载失败时不得静默替换为其他素材。

作品管理列表增加作品 ID、作者、关联图鉴卡、可见性、内容／运营状态、创建与更新时间、素材及举报筛选；详情提供已保存版本和卡面预览、素材版本、举报、处理与审计日志。限制公开、下架、恢复及复核沿用卡册运营流程，作用于小卡实验作品并同步权限、计数及缓存。额度与会员页增加小卡实验普通／PRO 上限及授权配置，调整前展示影响范围并保留审计记录。

| 操作 | 系统管理员 admin | 运营管理员 operation_admin | 内容运营 content_operator |
| --- | --- | --- | --- |
| 查看作品、详情、举报与日志 | 支持 | 支持 | 不开放 |

### 11.2 A01 作品首页：小卡实验原卡列表

- **布局**：顶部为返回、标题「作品」及现有「我的作品／作品收藏」范围入口；下方为「卡册｜小卡实验｜Live小卡」类型切换及作品数。小卡实验区显示搜索、新建和原卡网格；每项展示原卡图片、可识别的卡片信息及可见实验结果数。
- **交互**：点击原卡进入 A03；新建进入 A02。搜索基于图鉴小卡信息，排序建议按该组最近修改时间；作品收藏继续支持既有分组筛选，按作者＋原卡聚合。搜索、筛选和滚动位置在返回时保留。
- **状态**：本人无作品时显示简短空状态及「新建」；无搜索结果提供清除筛选；加载失败显示重试。访客无创建按钮，计数与可见列表一致；作品收藏失效引用按第 2.1 节单独展示。

### 11.3 A02 选择图鉴小卡

- **布局**：顶部返回和标题「选择小卡」；下方复用系统图鉴现有搜索、筛选和小卡网格，显示卡图与辨识信息，底部为「下一步」。选择区保持足够的图片识别面积。
- **交互**：单选任意有展示授权、当前可用的图鉴卡，不以已拥有或心愿状态限制；选中项显示勾选态，未选时「下一步」不可用。确认后带入卡 ID 和图片进入 A04；取消不创建作品、不消耗额度。
- **状态**：搜索无结果、列表失败和图鉴图片不可用分别展示相应状态；确认时若卡已不可用，保留搜索条件并提示重新选择。

### 11.4 A03 单卡实验结果列表

- **布局**：顶部返回及原卡基础信息；上方展示原卡缩略图和「新建实验」，下方以网格展示不同装扮作品。每项包括装扮缩略图、名称，作者可见公开／私密和「当前装扮」标识，以及更多操作入口。
- **交互**：点击缩略图进入 A05，并以该作品为焦点；「新建实验」直接带入当前卡进入 A04。本人更多菜单包括编辑、设为／取消装扮、公开设置和删除；切换装扮后更新标识及已拥有／心愿单。访客仅看到可访问作品，无创建及管理控件。
- **状态**：无实验结果时显示原卡及「新建实验」；无法显示图片时用占位并允许重试，不误显示其他作品。删除最后一个结果后，若从 A01 进入则返回并移除该原卡组；若从图鉴或收藏小卡详情进入则保留空状态。

### 11.5 A04 小卡实验编辑器

- **布局**：顶部为返回、标题、预览和保存；中央为完整小卡实时预览区；底部为「镭射／边框／装饰物」工具切换及对应素材面板。工具区保持滚动或折叠，避免遮挡卡面；必要时提供简洁的手势帮助入口。
- **镭射面板**：展示工艺缩略图、选中态、会员锁定态、反光强度和纹理密度滑杆、柔化开关；边框面板显示无边框、素材和层级切换；装饰物面板显示素材列表及当前选中项的删除操作。操作即时反映到预览。
- **交互**：在装饰物面板选中并移动、缩放、旋转或删除装饰；其他面板拖动卡面改变光照。工具面板切换时保留编辑参数。按住对比查看不带装扮的原图，松开恢复；「预览」打开当前未保存版本的 A05，「保存」校验权限和额度。
- **状态**：素材加载失败提供重试，保存中防止重复提交；保存失败保留编辑，成功后返回 A03 并定位作品。退出存在未保存修改时提供继续编辑／放弃；超额或使用无权素材时仅在保存等必要节点说明处理方式。无传感器权限不阻断编辑。

### 11.6 A05 样式预览与大图

- **布局**：深色或中性背景突出卡面，顶部返回及必要作品信息；中央为当前作品，两侧为同卡其他可见作品的缩小卡；底部显示焦点位置、必要的预览控制及可用作品操作。单件作品不显示虚构侧卡。
- **预览交互**：左右滑动或点击侧卡切换样式；点击／抽出中央卡进入大图。大图默认正面，点击翻面查看图鉴背面；支持拖动卡面改变反光、回正、自动转动及主动开启倾斜。大图内切换样式使用两侧按钮，避免与拖动反光和翻面冲突；系统返回或关闭先收回大图，再退出预览。
- **角色与状态**：本人已保存作品可进入编辑和作品操作；访客仅可阅读及对可访问作品收藏；编辑器预览不出现会误认为已保存的公开／设为装扮操作。无背面时明确提示；权限失效、图片加载失败和低性能静态降级遵循第 2.2 节。

### 11.7 A06 作品操作与隐私

- **操作菜单**：本人在结果列表或预览中选择「编辑」「设为装扮／取消装扮」「公开设置」「删除」。设为装扮时更新该卡唯一映射；若已有其他装扮，直接替换并更新状态，建议用简短反馈说明已生效。
- **公开设置**：展示当前作品缩略图及「私密／公开」单选状态，默认私密；确认后保存，取消不改变。作品公开不自动设为装扮，设为装扮也不自动公开。
- **删除确认**：展示作品名称与缩略图；若该作品为当前装扮，说明删除后将取消装扮并恢复原卡。确认删除后更新结果和数量，取消不变；失败时保留原状态并可重试。

### 11.8 A07 已拥有／心愿单

- 两个列表各自保留原有搜索、筛选、数量及操作；在列表工具区增加「普通／装扮」切换，当前模式清晰可见。普通模式显示原图；装扮模式显示本人指定作品的静态预览，没有有效装扮则显示原卡。切换不改变拥有或心愿关系。
- 点击小卡后保留现有详情行为，并在详情提供「小卡实验」入口进入该卡 A03；可在其中选择或取消装扮。首次模式与记忆规则采用第 4 节建议；当前访客无权读取的私密装扮不展示。

### 11.9 A08 访客主页与作品收藏

访客主页的小卡实验 Tab 使用原卡分组 → 可见作品列表 → 大图预览路径；只显示公开且可访问的结果和对应数量，点击原卡不得暴露其他私密作品。作品收藏使用相同路径并保留收藏分组筛选，按作者与原卡分组；收藏者可取消收藏，失效引用仅向收藏者本人显示不可访问占位。访客不显示创建、编辑、删除、设置隐私和设为作者装扮控件。

### 12.3 B03 素材分类列表

- **布局**：保留卡册原有素材场景入口，在「小卡实验」下分别进入镭射卡膜、边框、贴纸；每个分类有独立列表和筛选，显示预览、名称／ID、状态、会员范围、锁定预览、排序、更新时间、操作人及操作。
- **操作**：系统管理员可新增、编辑、预览及按状态上架／下架；仅符合删除条件的草稿显示删除。运营管理员可查看、筛选和预览；状态、排序及权益配置仅当前场景生效。
- **状态**：草稿、上架、下架有明确标签；空列表提供对应分类新增入口，失败可重试。卡册贴纸即使已上架，也不会自动出现在小卡实验选择器。

### 12.4 B04 素材新增／编辑与预览

- **通用表单**：名称、唯一 ID、资源或效果配置、会员范围、锁定预览、排序；显示所属场景和分类，保存后不可改所属场景及类型。新增 ID 重复时报错；未保存离开时提示，失败保留输入。
- **镭射卡膜表单**：配置工艺及渲染版本／参数，在示例卡上预览不同角度、反光强度和密度；不提供导入卡册素材的入口。
- **边框表单**：上传或选择合规透明边框资源，预览不同卡面适配及贴纸上下层关系；不提供作为卡册边框发布的入口。
- **贴纸表单**：选择已有可授权的共用贴纸资源或新增资源，并创建小卡实验独立场景条目；显示资源来源、版本以及当前场景配置。预览透明边缘、卡面放置与缩放，不改动卡册场景条目。
- **动作与状态**：支持保存草稿、场景预览和符合条件时上架；资源解析、授权或预览失败阻止上架，明确标出失败原因。预览数据不创建用户作品。

### 12.5 B05 素材状态变更确认

确认界面展示素材名称、类型、所属场景、当前与目标状态、受影响的新增使用范围和历史作品处理。上架执行完整校验；下架停止该场景新增使用并保留正常历史视觉；删除仅对符合条件的草稿开放。共用贴纸的普通下架不影响卡册条目；涉及授权撤图的强制禁用明确列出受影响场景和缓存清理范围，并记录原因与操作日志。取消不改变状态。

### 12.6 B06 额度与会员

展示普通／PRO 的小卡实验作品数量上限、当前配置及素材权益说明，与卡册额度分开；系统管理员可编辑，运营管理员只读。保存前校验数值，降低额度时展示前后值与受影响用户／作品范围并确认；取消不生效。配置变更后已有作品保留，超过新上限时阻止新增，操作记录纳入审计。支付和订单入口遵循现有实际能力。

### 12.7 界面验收补充

1. 从 A01 经 A03 到 A05，以及从图鉴／收藏详情直接进入 A03，返回后均保留来源和位置；同卡多个样式的焦点、数量和装扮标记正确。
2. A04 编辑未保存内容进入 A05 再返回，内容和位置保持；大图拖动、翻面及切换按钮不会互相误触，减少动态效果时仍可完成预览。
3. A06 隐私和装扮操作相互独立；访客 A08 不出现作者控件，不泄露私密作品或数量。
4. B03–B05 分别验证三类素材及草稿、上架、下架状态；共用贴纸只影响目标场景的配置，强制撤图按底层资源跨场景生效。
5. B01、B02、B06 的不同角色页面与服务端权限一致；筛选失败、无结果、权限不足及保存失败均有可辨别状态。
