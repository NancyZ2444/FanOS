# 本地 UI、社交与原图定位扫描验证

日期：2026-10-27（含本日后续 12 项验收修复）。仅更新本地代码、API、管理平台与 iOS 模拟器；未提交 Git、未部署云端、未构建 Android。

## 本轮变更

- 移除每日翻卡两处说明、首页每日翻卡副说明、反馈空状态副说明，并清理对应留白。
- 相册创建不再选择视觉风格。按最新要求，BOOK 模式恢复实体栏位、口袋与装订，CARDS 模式仍为直接小卡；保留已有封面、背景、文字、贴纸与画笔数据，不迁移或删除作品。单面/双面直接在配置页选择。
- 卡片预览移除下方操作说明和官方图鉴按钮；故事保留正文、移除标题，整体可滚动，不再被固定高度裁切。点击作品默认预览，菜单不再重复“查看相册”，可见性动作按当前状态显示“设为公开 / 设为私密”。
- 用户搜索、关注和粉丝列表接入真实数据。计数使用服务端结果，失败不修改状态，重复操作防重入，账号切换清理缓存。
- 保留 AI Scan 原有拍摄界面，默认直接采用原图定位与自动匹配流程，不必再点独立入口。结果页更多菜单仍可进入经典结果作对比。
- 新流程自动定位后匹配，原图编号、缩略图和单卡面板联动；区分推荐、待确认、无匹配及匹配失败。失败对象可单独重试，保留其他结果与原编号。
- 推荐和收藏状态独立。相似候选确认后才能保存。新增原子 `ensure_owned` 操作，重复对象、重复扫描和重试不会自动增加数量或覆盖已有数量；心愿单独立。
- 图鉴推荐图片与信息可跳转详情；真实相似候选按相似度去重展示，无候选不虚构推荐。主心愿单/拥有按钮增加图标，已保存状态可点击确认撤销，两个关系互不影响。
- 匹配、待确认、未匹配分别使用紫、橙、灰；相似度采用粗体徽标。新扫描根据真实匹配几何或明确人像方向提供 90°/180°/270°显示校正；无可靠依据不猜方向。仅旋转显示像素，不修改原图、检测坐标、保存的裁剪图及匹配阈值。
- “找不到卡？”直接进入可选线索反馈表单，支持正面更换、背面上传及两面手动裁剪，默认沿用已有扫描图。服务端附带可信扫描上下文，进入现有审核流程。资料不完整不能直接发布。提交失败保留表单，成功或取消返回原对象。

## 人工验收建议

1. 使用自己的测试账号登录，检查首页、每日翻卡和反馈空状态说明是否已删除。
2. 新建及查看旧相册，确认没有视觉风格选项、单/双面首层可选；BOOK 有真实栏位，CARDS 预览故事完整可读，已有自定义内容未丢失。
3. 西瓜桑搜索 `Fan`，打开运营主页，对照关注与粉丝列表。
4. 扫描页直接从相册导入多卡照片；核对原图编号、缩略图、详情联动、三色状态及面板展开时当前对象仍可见。横放或倒置卡应在有可靠方向依据时转正，原图不变。
5. 分别检查推荐、相似候选、无匹配及图鉴详情跳转；重复标记拥有应保持数量，已拥有/已在心愿单可以点击撤销，两个关系互不影响。
6. 提交一条测试反馈前先确认愿意产生真实本地记录；返回后应保留对象和位置，不自动生成图鉴。
7. 更多 → 经典结果，对比旧版。新流程的返回状态只在当前登录会话内保留，不宣称跨重启持久保存。

将来发布云端时需要同步部署本轮 API 与 App：`ensure_owned`、失败项重试和 `SCAN_CLUE` 为配套接口能力。本轮没有执行任何云端发布。
