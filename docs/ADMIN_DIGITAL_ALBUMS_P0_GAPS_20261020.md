## 3. 需要用户确认的差异

以下均为待确认建议，不是已实施规则。可以按编号调整；“按建议执行”表示同时接受这些功能边界及 Q2 的初始配置。

### Q1：是否同步更新 App 的素材选择和渲染？

**现状与差异**

- 后台不能通过上传图片使当前 App 自动支持图片贴纸、图片背景或图片书架。
- App 背景推荐色写在客户端，后台背景配置没有进入实际选择器。
- App 当前贴纸添加函数在内页直接返回，只开放封面。
- PRD 要求图片素材、颜色管理、会员范围和 App 预览，这些必须涉及 App。

**建议确认**

1. 本次允许 App、API、后台一起更新，全部先在本地验证。
2. 类型采用 `SHELF / BACKGROUND / COLOR / STICKER`；背景通过封面 / 内页 / 两者区分适用场景。SVG 和其他装饰类型暂缓。
3. 图片贴纸支持 PNG/WebP；背景支持 JPG/PNG/WebP；书架支持图片与现有配色；保留现有符号贴纸、纯色和渐变。
4. 背景与颜色选择接入后台上架资源。素材支持全部用户 / PRO，并支持非会员锁定预览开关。
5. P0 先保留当前 App 编辑范围：贴纸用于封面，内页仍按当前卡位布局；本次不自动扩展内页自由贴纸编辑。后台应完整预览已经保存的画布元素。

**需确认**：是否接受以上范围；如希望本次同时开放内页贴纸编辑，请单独指出。

### Q2：取色是本次新增 App 功能，还是只预留配置？

**现状与差异**

当前 App 只有选系统颜色、手填 HEX 和调整渐变，没有图片取色入口或分析功能。新增额度字段本身不会产生可消费的能力。

**建议确认**

- 为完成 P0 闭环，本次增加“从图片取色”，允许选择已有小卡图片或本机照片。所选照片仅用于分析颜色，不因此变成相册小卡或公开图鉴内容。
- 成功产生一次分析结果计一次；失败、取消、打开面板、选择系统色、调整已有结果不计次。
- 服务端同时检查每日 / 每月额度，处理重复请求和并发扣次；建议按北京时间日历日、自然月重置。
- 初始额度建议采用 PRD 示例：普通用户 **3 次/日、20 次/月**；PRO **30 次/日、300 次/月**，后台可调整。
- 现阶段只展示会员要求和额度提示，不新增付费购买流程。

**需确认**：是否新增完整取色功能，以及上述初始额度和重置时区。PRD 中的数值是示例，当前尚未写入配置。若选择仅预留后台配置，需将 App 取色与消费闭环列为未完成项。

### Q3：限制公开、下架后的修改与恢复如何衔接？

**现状与差异**

当前只存在一个公开限制标记，两种处理无法区分；作者修改后仍无法公开发布，也没有申请复核入口。复制相册生成新作品，不继承原作品的限制状态，可能绕过原处理。

**建议确认**

- 独立维护正常 / 限制公开 / 已下架运营状态，保留用户自身的草稿 / 已发布 / 已删除及公开 / 私密设置。
- 两类限制都阻止他人访问及公开传播，保留作者原作品供查看和编辑。
- 限制公开后允许作者修改并申请复核；提交不自动恢复公开。运营恢复后，作者再主动发布修改内容。
- 下架后也不因作者保存而恢复；通过运营复核决定是否恢复。
- 恢复只解除运营限制，不把私密作品改成公开，不复活已删除作品，也不自动发布最新编辑内容。
- 受限制作品不能通过直接复制获得可公开传播的副本；建议限制解除前阻止复制，并展示具体原因。
- 原有 `is_moderated=true` 数据映射为“限制公开”；保留原审核原因和日志。

**需确认**：是否补申请复核流程并采用以上恢复、复制规则。这里会改变 App 操作，不能只改后台按钮名称。

### Q4：P0 默认审核哪个版本？

**现状与差异**

后台查看当前编辑数据，访客看到最近发布快照。PRD 要求审核接近用户实际看到的内容，但“编辑 / 发布双版本切换”又明确放在 P1。

**建议确认**

- P0 已发布作品默认预览最近发布快照；从未发布的作品预览编辑内容。
- 打开详情重新获取数据，明确标注预览版本；运营审核不能以过期列表缓存替代详情。
- 本次不做 P1 的双版本切换；若 Q3 的复核需要审核修改内容，则在复核处理场景提供待复核内容预览，不改变普通作品详情的默认版本。
- 前后台不替作者修改或发布作品。

**需确认**：是否采用上述 P0 默认预览及复核例外，双版本对比仍放 P1。

### Q5：下架素材、到期会员素材能否随作品复制？

**现状与差异**

- 自定义贴纸依赖上架素材接口解析，下架后可能丢失原视觉。
- 当前历史允许规则是按素材 ID 判断，因此原作品已有该素材时，可能继续新增同款实例。
- 复制作品会复制素材引用。PRD 明确原作品保留、新作品不能新增，但没有单独定义整本复制。

**建议确认**

- 保存素材 ID 和必要渲染快照；已放置的素材、下架书架样式、会员到期前使用的素材继续正常显示。
- 原实例可以保留并调整位置、尺寸；删除并保存后不能重新添加不可用素材，也不能新增同款实例。
- 复制算新作品：如果包含下架素材或当前已无权限使用的 PRO 素材，先阻止复制并列出具体素材。原作品保持原样，用户可恢复权益或调整素材后再复制。
- 视觉文件更换不直接覆盖历史实例；P0 采用必要渲染快照和不可变文件引用，不建设完整 P2 素材版本管理界面。

**需确认**：复制是否采用上述限制。若需要“复制也保留旧素材使用权”，需明确这是新作品使用限制的例外。

### Q6：会员素材不可用时是否只提示，不增加购买流程？

**现状与差异**

当前有普通 / PRO 授权和到期校验，没有本模块可复用的完整付费升级流程；PRD 的“升级会员”入口不能直接假设已具备购买能力。

**建议确认**

- 非会员按配置可看到带 PRO 标记的锁定素材，点击说明需要 PRO；不允许真正加入作品。
- 会员到期不删除旧素材和超额相册 / 页数；限制新增。
- P0 不新增支付或订阅购买页面；继续复用既有人工授权能力。

**需确认**：接受提示式会员入口，购买流程另行规划。

### Q7：本次是否保留现有两级会员与角色边界？

**现状与差异**

当前会员模型和接口固定 `NORMAL / PRO`，没有独立会员等级注册表；PRD 提出读取可扩展会员体系及新增素材运营 / 会员管理员角色。

**建议确认**

- P0 继续保留普通 / PRO 两级及旧接口值、现有授权与到期数据；本次不新建整个平台的会员等级管理和 PRO PLUS。
- 新增权益 / 素材配置结构按会员标识关联，预留扩展；不是仅增加固定 `is_pro` 字段。
- 每页卡位仍为全局配置，保持现值，不按示例重置。
- 保留现有权限：管理员维护权益和素材，运营管理员处理作品。暂不新增角色管理；页面和 API 同时校验权限。

**需确认**：接受这一 P0 兼容范围，还是本次同时建设可配置会员等级和专用角色。

## 5. P0 与后续阶段的界线

- Q2 所需基础用量记录属于执行额度的必要数据；独立用量查询管理页面仍属 P1。
- P0 历史渲染快照用于保证已有作品，不等同于 P2 完整版本管理。
