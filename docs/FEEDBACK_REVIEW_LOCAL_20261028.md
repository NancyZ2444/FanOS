## 1. 发行日期误拦截

目标反馈：`fb_a0cfe803dacf486d98681015381ac631`，Wonyoung / IVE，建议发行日期为 `2026-10-01`。

原成员关系的 `start_date=2026-10-09` 来自自动创建关系时的默认录入日期。创建审计证明运营没有填写真实入团日期；该关系无退出日期，状态仍为在团。旧逻辑把录入日作为真实起点，因此误拦截 10 月 1 日。

本次统一了关系校验与展示：

- 新建或导入时自动建立的成员关系，明确标记入团日期未核实。
- 既有关系仅在创建审计能证明自动建立、没有明确维护的日期、关系未被改写时，识别为未核实起点；不会仅凭“创建日等于入团日”放宽限制。
- 人工维护的真实起止日期、退出日期、作废关系继续校验；历史小卡仍按发行归属处理。
- 未核实日期在详情中显示为空值，不把录入日继续展示为真实入团日；后台原值保留。
- 成员经历变更时的历史卡保护也使用同一规则。

使用真实本地数据的只读 SQLite 连接执行完整关系校验，`2026-10-01` 返回无错误。原小卡发行日期仍为空、原成员数据库日期仍为 `2026-10-09`，真实反馈没有被自动发布。证据：[只读验证](../output/membership-date-fix/readonly-validation.json)。无需数据库迁移，服务加载新代码即可生效。

## 2. 处理结果与发布分开

图鉴新增（小卡及通用图鉴补充）和图鉴信息错误共用处理组件。

| 操作 | 公开说明 | 用户动态 | 正式图鉴 |
| --- | --- | --- | --- |
| 保存草稿／保存审核意见 | 可保存内部拟用说明 | 不更新、不通知 | 不发布 |
| 提交已采纳 | 默认“已采纳，待发布后更新图鉴。”，可修改 | 显示已采纳、待发布 | 尚未更新 |
| 提交未采纳 | 切换选项时清空，必须填写 | 同步说明，保留提交记录 | 不更新 |
| 提交信息缺失待补充 | 切换选项时清空，必须填写 | 同步补充要求 | 不更新 |
| 已采纳详情中点击发布 | 使用已提交的审核快照和说明 | 发布成功后再次同步 | 校验成功后更新 |

编辑表单底部的主操作是“提交处理结果”。“发布小卡并收录”或“确认更新并发布”仅在已采纳的只读详情中出现；通用图鉴补充对应“发布并收录”。

服务端同样校验此规则，不能绕过界面直接发布。发布使用已提交的字段、采用值和公开说明；请求不能临时换入未确认内容。关联对象变化时要求重新核对。再次保存内部修改会取消后台发布资格，必须重新提交处理结果，私有修改不会产生用户通知。

发布失败会整体回滚，不推进记录版本、不重复通知，保留已提交内容以便修改重试。完整小卡编辑器也不能绕过关联反馈流程；若历史草稿已进入待审核状态，可回反馈提交采纳后原子完成发布。

额外修正了审核字段数量上限（与用户提交的 30 项一致）、通用图鉴补充重提被旧内部草稿覆盖、空小卡库刷新造成页面重新挂载等相关问题。

API 采用兼容扩展：`action=decide`、`review_decision=ACCEPTED/REJECTED/NEEDS_INFO`；管理员详情返回 `review_decision`、`can_publish`。未正式发布仍使用已有 `PENDING` 结果码，避免 App 将采纳误认为正式收录。已发布或已处理的历史记录保留，旧草稿需要先提交明确处理结果。

App 本轮未改动或重打包。小卡补充和纠错继续使用现有补充入口；通用 `MISSING_CATALOG` 的后台待补充状态与 API 重提可用，但当前 App 尚无该类型的专用补充入口，此既有差异未在本轮新增移动端功能。

## 3. Other 封面上传

Other 新增、编辑表单将外链输入框替换为公共图片上传组件，支持 JPG / PNG / WebP 文件上传、预览、更换。文件通过现有上传接口写入媒体存储；本地环境实际保存图片文件，业务数据只记录平台返回的媒体地址，不记录本次文件的外部图片链接，也不新增远程下载流程。

替换失败保留原封面，编辑其他字段不会丢失已有图片；已发布只读状态不能更换。历史外链不批量转换，以免影响已有数据。

## 6. 本地验收步骤

1. 刷新后台，进入“图鉴信息错误”，打开目标反馈并编辑；核对采用的发行日期为 `2026-10-01`。
2. 选择“已采纳”，检查默认公开说明，提交处理结果。详情应显示“已采纳，待发布”。
3. 运营确认后再点击“确认更新并发布”；后端执行发行归属及其他业务校验。
4. 在测试反馈上切换“未采纳／信息缺失待补充”，说明应清空，留空不能提交；内部草稿不产生用户通知。
5. 在 Other 新增抽屉上传图片，确认预览并保存；编辑时原图应回填。
