# Fan OS 后台 UI 与操作规范整改

更新日期：2026-10-13。范围：React 管理后台；保留现有业务流程、权限与 API 数据规则。本次无需数据库迁移，不批量修改已有记录，不涉及 App 安装包或移动端页面。

## 公共规范与实现

统一入口位于 `apps/admin/src/design/` 和 `apps/admin/src/components/admin.tsx`。新页面应复用这些能力，避免各自增加一套尺寸和交互样式。

| 能力 | 实现位置 | 约定 |
| --- | --- | --- |
| CSS 变量 | `design/tokens.css` | 间距 4 / 8 / 12 / 16 / 24 / 32；页面与模块间距 24；卡片内边距 20；字段间距 16；按钮间距 8 |
| 组件主题 | `design/theme.ts` | 普通控件高 36；紧凑按钮高 28；按钮横向内边距 16；图标 16；字体 24 / 16 / 14 / 12；圆角 6 / 8 |
| 公共布局样式 | `design/components.css` | 标题、筛选、工具栏、表格、分页、详情、抽屉和弹窗；特定业务样式继续留在 `styles.css` |
| 页面组件 | `components/admin.tsx` | PageHeader、FilterBar、TableToolbar、Table、RowActions、EmptyState、DetailFields、BusinessData、RecordId |
| 新增编辑 | 同上 | Form、Modal、Drawer、useFormGuard、useSingleSubmit；共享字段校验、未保存保护、异步保存与重复提交锁 |
| 中文展示 | `design/format.ts` | 字段、状态、布尔值、业务日志动作；空值为“—”；时间采用北京时间（UTC+08:00）和 `YYYY-MM-DD HH:mm` |
| 删除检查 | `components/catalogDeletion.tsx` | 对象名、1 条记录、不可恢复提示、关联阻断原因及查看关联内容入口 |

侧栏负责组合、艺人、专辑、活动、其他来源、小卡等同级模块切换。页面内保留当前模块的状态、版本、成员经历等业务分类。压缩品牌和固定底部区域，移除工作空间卡片，快捷创建使用等宽网格。

普通列表采用“标题 → 筛选 → 列表工具栏 → 表格 → 分页”。搜索与选择条件变更后自动筛选；数字相册远程检索使用 300ms 防抖并取消过期请求，避免旧结果覆盖新条件。基础条件默认展示，低频条件折叠到“高级筛选”；重置同时清除基础与高级条件。记录总数集中在分页，状态数量仅用于分布。新增位于工具栏右侧，导入等为次操作；行操作采用“查看、编辑、更多”，不存在的操作不强行显示。

表格统一表头高 44、普通行不低于 56、缩略图行不低于 72。长内容截断并可查看完整文本，编号弱化且可复制。空表格取消固定宽度与横向滚动；有数据时仅在表格内部允许必要滚动。分页会在删除或筛选后回到有效页，支持调整每页条数。

详情分为基本信息、关联内容、发布信息、系统信息，保留专门的成员、公司、版本、来源、索引与审计页签。低频的空可选字段折叠；已有值仍显示。右上角提供编辑；已发布或待审核对象按原业务规则禁用直接编辑并提示原因。

## 新增、编辑与删除规则

- 同一业务对象新增和编辑复用表单，字段顺序与校验一致。组合等多字段对象使用抽屉，小卡使用独立向导，公司/标签/版本等使用弹窗。
- 普通表单底部为取消、保存。图鉴表单保留“保存草稿”“提交审核/发布”，避免混淆保存与发布。
- 保存显示加载状态并阻止重复请求。校验或接口失败保留输入；成功刷新列表；编辑回填既有值。
- 取消、关闭、侧栏跳转、浏览器返回及刷新均有未保存保护。继续编辑保留输入，放弃修改退出。
- 删除与下架、归档保持不同动作。删除放入“更多”且使用危险色；确认说明名称、数量、影响与可恢复性。
- 沿用现有数据约束：从未发布的草稿允许删除但仍检查下游引用；曾发布后下架或归档的对象必须解除全部上下游关联。界面提供具体阻断原因和关联内容入口，不绕过服务端校验。
- 批量栏仅在选中记录后出现，并显示已选数量。现有图鉴批量 API 是原子事务：一项不满足条件则整批回滚；界面保留选择与错误原因，不报告不存在的“部分成功”。导入保留现有逐行错误和修正功能。
