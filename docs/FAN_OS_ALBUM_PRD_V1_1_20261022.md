## 2. 产品定位与范围

### 2.1 产品定位

数字相册是使用 Fan OS 官方图鉴小卡进行整理、设计与展示的工具。用户可以创建翻页式相册，也可以创建立体卡片展示作品，通过个人主页公开展示、点赞、收藏和分享。

统一用“卡册作品”表示两种类型的共同管理对象；“相册模式”特指有封面、内页和固定卡位的作品；“卡片模式”特指以独立卡片序列进行轮播展示的作品。它们均不等同于音乐专辑、用户私人照片相册或实体小卡拥有记录。

### 2.2 核心原则

- 官方图鉴驱动：作品中的小卡引用可用的官方 Card ID，不产生新的图鉴主数据。
- 类型固定：一份作品只有一种类型，创建成功后终身固定；同一用户可分别创建两种作品。
- 内容独立：两份作品即使引用相同小卡，增删、排序、设计和发布均互不影响。
- 收藏独立：加入作品不等于拥有实体小卡，也不自动加入“我的收藏”中的小卡收藏。
- 低门槛创建：允许使用尚未个人收藏的官方小卡，允许先创建空白私密草稿。
- 非破坏式权益：会员到期、额度降低不自动删除用户已保存的作品和页面。
- 发布版本稳定：保存编辑与对外发布分离，访客只查看有权限访问的已发布版本。

### 2.3 范围

| 范围 | 本版要求 |
| --- | --- |
| 作品管理 | 书架 / 列表、搜索排序、创建、编辑、预览、复制、删除、公开 / 私密 |
| 相册模式 | 自由封面、固定卡位内页、页面管理、单面 / 双面、真实 / 极简风格 |
| 卡片模式 | 独立选卡、排序、主卡、作品故事、展示字段、背景、立体轮播、抽卡和正反面预览 |
| 共用能力 | 官方选卡、系统素材、取色、自动保存、发布、点赞、收藏分组、分享链接 |
| 后台 | 作品管理与复核、额度与会员授权，以及分开的书架主题 / 相册封面素材 / 相册内页素材 / 卡片背景管理 |
| 原需求缺口 | 内页自由文字 / 贴纸 / Emoji、异步封面缩略图，保留需求并单列实现状态 |
| 后续范围 | 支付购买、积分扩容、音乐和音效、书架自由装饰、自定义上传贴纸、AI 贴纸、分享海报、独立 Web 阅读页、运营统计大屏 |

本版不承接会员价格或成本测算文档中的未确认商业化方案；仅沿用现有普通 / PRO 权益结构。

## 3. 两种模式的业务规则

### 3.1 功能对照

| 项目 | 相册模式 BOOK | 卡片模式 CARDS |
| --- | --- | --- |
| 适合场景 | 按成员、专辑、系列整理，设计一本可翻阅的小卡册 | 少量精选小卡、主题展示和个人故事 |
| 内容单位 | 封面 + 内页 + 卡位 | 独立小卡实例序列 |
| 阅读方式 | 从封面进入，左右翻页 | 立体叠放，左右切换，抽出小卡查看 |
| 小卡顺序 | 页面顺序、页内卡位顺序 | 加入顺序，可手动拖动排序 |
| 视觉标识 | 用户设计的封面 | 主卡、作品名称与背景生成的展示封面 |
| 核心编辑工具 | 封面设计、布局、页面管理、选卡、背景 | 选卡、排序、主卡、故事、信息字段、背景 |
| 单面 / 双面 | 支持 | 不提供 |
| 真实卡册 / 极简数字 | 支持 | 不提供；使用卡片叠放展示 |
| 页数与格数 | 按页数额度；每页 1～9 格 | 无页数、无格数、无隐藏内页 |
| 自由封面编辑器 | 支持 | 不提供 |
| 创建后改为另一种类型 | 不允许 | 不允许 |

卡片模式的自动展示封面规则属于本次分离后的建议方案；保留当前主卡和背景能力，不新增另一套自由封面编辑器。

### 3.2 类型不可变

1. 创建请求必须携带作品类型，创建成功后不可修改。
2. 编辑器、作品设置、阅读页、分享访问页、后台预览均移除另一种模式的切换入口。
3. 复制作品只能复制成原类型，不提供“转换为另一模式”或“复制为另一模式”。
4. 用户如需另一种作品，应重新创建并重新选卡。选择相同官方小卡不会形成作品之间的内容同步。
5. 服务端拒绝修改作品类型、跨类型写入配置和访问错误类型编辑操作；不能仅隐藏 App 按钮。
6. 创建前在说明页比较、选择两种方案不属于作品转换；创建之后不能返回选择页修改该作品类型。

### 3.3 仍然允许的展示调整

书架 / 列表、相册单面 / 双面、相册真实 / 极简、小卡正面 / 背面属于各自场景内的展示调整，继续支持。编辑 / 预览也继续支持，不能与作品类型混为一谈。

### 3.4 官方小卡与实例

- 同一作品可以重复使用同一官方小卡；添加时提示“该小卡已在本作品中，仍要添加吗？”，确认后保留独立实例。
- 相册模式以卡位 ID 区分放置实例；卡片模式以独立卡片实例 ID 区分重复项，不能只用 Card ID 排序。
- 不同作品可以跨组合、艺人、专辑、活动混合选卡。
- 删除作品、移除实例不删除图鉴小卡，不改变个人小卡收藏；取消个人收藏也不移除作品内实例。
- 图鉴小卡不可用时保留位置与引用，显示不可用占位。图鉴展示权限及图片授权限制同时作用于作品预览、缩略图和分享，不得通过缓存继续展示被禁止的图片。

## 4. 容量、权益与计数

### 4.1 默认权益

| 权益 | 普通用户 | PRO | 口径 |
| --- | ---: | ---: | --- |
| 作品总数 | 10 | 30 | 原额度沿用；两种类型合并计数为建议待确认 |
| 每本相册内页数 | 10 | 20 | 仅 BOOK，现有沿用 |
| 每页卡位 | 1～9 | 1～9 | 全局上限可配置，现有沿用 |
| 相册封面小卡 | 最多 1 张 | 最多 1 张 | 封面不算内页 |
| 每份卡片作品的小卡数 | 建议 15 | 建议 15 | 当前 App 编辑上限为 15；服务端独立额度与后台配置为本次新增建议 |
| 每日取色 | 3 次 | 30 次 | 现有默认值，后台可配置 |
| 每月取色 | 20 次 | 300 次 | 现有默认值，后台可配置 |
| 官方素材范围 | ALL | ALL + PRO | 具体可用内容还须满足上架状态与使用场景 |

“15 张”不是由原主 PRD 的页面容量推导，也不是用户已确认的会员差异。本文建议保持当前 App 使用习惯，并新增可配置的普通 / PRO 两档卡片容量，后续可独立调整。

### 4.2 计数规则

| 指标 | 计算规则 |
| --- | --- |
| 用户作品数 | 本人未删除的两类作品总数；草稿、公开、私密、受限作品均计入；收藏他人作品不计入 |
| 相册页数 | 实际可编辑内页，包括空白页；不含封面及双面阅读的空白占位 |
| 相册小卡数 | 已占用的内页卡位数，重复实例分别计数；封面小卡单独显示，不计入内页卡数 |
| 卡片作品小卡数 | 独立序列中的实例数，重复实例分别计数；主卡只是其中一个实例，不额外计数 |
| 卡片作品页数 | 不适用，界面显示“—”或不展示；不能伪装为 1 页 |
| 复制 | 整份复制占用新作品额度；复制内页占用新页额度；复制保留原类型 |
| 删除 | 删除作品释放作品额度；删除内页释放页额度；卡片移除实例释放该作品卡片容量 |

### 4.3 额度达到上限

- 创建、复制、增加页面、增加卡片均由服务端校验，展示当前使用量、上限和具体原因。
- 相册页数与卡片容量分别校验，卡片模式不消耗“页数”额度。
- 允许先查看创建预览；实际创建按钮根据额度状态提供“查看权益”等引导，不创建超额草稿。
- 批量添加剩余容量不足时，明确提示剩余可放置数量；不得静默丢弃部分选中项。
- 当前仅提供权益说明及已有会员授权能力，不能让“升级”按钮跳转不存在的支付流程。

### 4.4 会员到期与额度调低

保留已有作品、页面、卡片和素材实例，允许查看、调整排序、修改既有内容、删除及重新发布合法内容；新增或复制必须满足当前额度及素材使用权。

例如到期后保留 25 份作品和 18 页相册，但不得继续新增第 26 份作品或第 19 页。历史卡片作品超过新上限时同样保留全部实例，禁止继续增加数量。编辑已有超额内容不得因保存校验而被强制截断；替换既有小卡不视为增加实例数量。

## 5. App 入口、书架与列表

### 5.1 入口与分类

- 沿用“我的收藏 → 卡册”入口及个人主页“卡册”入口，不新增一级导航。
- 我的收藏中区分“我创建的”“草稿”“我收藏的”；个人主页沿用创建 / 收藏分类，草稿不对访客展示。
- 个人主页公开开关使用“公开我的卡册”，避免与私人照片的相册设置混淆。
- 新增类型筛选：全部、相册模式、卡片模式。它只筛选列表，不转换作品。
- 本人访问提供创建和管理操作；访客只能查看符合公开与运营状态条件的内容。

### 5.2 页面布局

顶部包含作品数量、搜索、类型筛选、书架 / 列表、排序、创建按钮。记忆当前用户的书架 / 列表偏好；默认书架视图。

| 区域 | 相册作品 | 卡片作品 |
| --- | --- | --- |
| 视觉 | 设计封面 | 主卡与背景形成的卡片展示封面 |
| 类型标识 | 相册模式 | 卡片模式 |
| 数量 | X 张小卡 · Y 页 | X 张小卡 |
| 状态 | 草稿、私密、受限、待复核等按需展示 | 同左 |
| 点击 | 草稿进相册编辑；完成作品进相册阅读 | 草稿进卡片编辑；完成作品进卡片阅读 |

书架采用响应式 2～3 列陈列，列表展示名称、缩略图、数量、更新时间和状态。卡片作品不会显示页数或翻页装饰。

### 5.3 搜索、排序与管理

- 搜索作品名称；创建作品按最近更新、最近创建、名称排序；收藏作品沿用收藏时间等现有排序口径。
- 支持刷新、分页、加载失败重试、空列表和无搜索结果状态。
- 本人作品菜单包含查看、编辑、重命名、可见性、复制、删除；不存在更改作品类型操作。
- 复制自己的作品得到新的私密草稿、新 ID 和相同类型；不复制点赞、收藏、举报或复核记录。
- 受限或下架作品不能通过复制绕过处理；含不可新增使用素材时按第 10 章阻止复制。
- 删除前确认；删除不会影响个人小卡收藏及官方图鉴。

### 5.4 书架主题

沿用系统书架主题，如奶油白、浅粉、浅木、银色金属、极简等；实际可选主题由后台上架配置决定，不将示例名称写成固定数量要求。主题是用户级偏好，对该用户书架统一生效，不修改作品内部背景。

无作品文案：“创建你的第一份小卡作品。”；搜索无结果时提示清除筛选；不可访问的收藏保留说明和移除入口。

## 6. 创建流程与两种模式预览

**本次调整。** 创建分为“选择模式并预览”和“填写对应配置”两步；未提交创建之前不生成作品、不占用额度。

### 6.1 流程

进入创建 → 展示两种模式说明 → 查看预览并选择模式 → 填写名称及本模式配置 → 点击创建 → 服务端校验并一次性创建私密草稿 → 进入对应编辑器。

创建操作需防重复提交；网络超时重试不得生成两份作品。创建失败时不留下半成品记录或扣占额度。

### 6.2 模式说明卡

| 内容 | 相册模式 | 卡片模式 |
| --- | --- | --- |
| 标题 | 相册模式 | 卡片模式 |
| 说明文案 | 像整理实体卡册一样，设计封面、安排内页，翻页查看小卡。 | 将精选小卡立体叠放，左右滑动欣赏，设置主卡与专属背景。 |
| 能力标签 | 自由封面 / 每页 1～9 格 / 单双面翻页 | 立体轮播 / 小卡排序 / 主卡与故事 |
| 预览按钮 | 预览相册效果 | 预览卡片效果 |
| 选择操作 | 选择相册模式 | 选择卡片模式 |

两张卡同级展示，选中态清晰。首次创建必须明确选择一种类型；返回上一创建步骤可保留尚未提交的表单。

选择区域持续展示：“创建后无法更换模式。你可以分别创建相册作品和卡片作品。”不需要增加重复确认弹窗。

### 6.3 预览内容与交互

| 预览 | 最少内容 | 可体验操作 | 必须说明 |
| --- | --- | --- | --- |
| 相册 | 示例封面 + 至少 2 页不同格数的小卡 | 打开封面、翻页、比较单面 / 双面、查看小卡正反面 | 可以设计封面和内页；页数受权益限制 |
| 卡片 | 至少 3 张示例小卡形成叠放效果 | 左右滑动、切换主卡焦点、抽出查看、正反面和收回 | 没有内页和翻页布局；小卡按独立序列展示 |

- 预览显著标注“示例效果”，使用平台可展示的示例图鉴素材。
- 预览数据与用户作品隔离；示例小卡、文字、背景不随创建保存到新作品。
- 预览不增加作品数量、不扣取色次数、不新增个人小卡收藏，也不产生发布或社交记录。
- 关闭预览返回选择页，保留当前选项；“使用此模式”可直接选中该类型并进入配置步骤。
- 示例加载失败提供静态示意和重试，仍能阅读说明和继续选择。减少动态效果设置下使用静态预览。
- 预览不受用户剩余额度影响；创建仍执行额度校验。

### 6.4 创建字段

| 字段 | 必填 | 两类通用 | 相册模式 | 卡片模式 |
| --- | --- | --- | --- | --- |
| 作品类型 | 是 | 由上一步确定 | BOOK | CARDS |
| 名称 | 是 | 1～50 字符，去除首尾空白后不得为空 | 可用默认“我的小卡册” | 可用默认“我的卡片作品” |
| 简介 / 故事 | 否 | 最多 200 字符，可创建后编辑 | 作品简介 | 作品故事，复用同一文本字段 |
| 单面 / 双面 | 是，仅相册 | — | 默认单面，可预览后选择 | 不展示、不提交 |
| 真实 / 极简 | 是，仅相册 | — | 默认真实卡册 | 不展示、不提交 |
| 可见性 | 系统默认 | 私密 | 同左 | 同左 |

创建相册后进入封面编辑器，初始 0 个内页、0 个卡位；用户主动新增内页，默认格数为 9 与后台每页卡位上限中的较小值，新增空白页计入页数。创建卡片作品后进入独立卡片编辑器，展示“添加第一张小卡”，初始 0 个实例，不创建封面画布、内页或卡位。

创建后设置页仅以只读方式展示“作品类型”，说明无法更换。返回创建入口只可创建新作品。

## 7. 相册模式：封面与内页编辑

### 7.1 编辑器结构

顶部提供返回、作品名称、撤销、重做、预览、完成；中间展示当前封面或内页；底部根据当前对象展示编辑工具。现有撤销历史上限为 40 步，撤销与重做只作用于编辑内容。

选中小卡时展示更换、移动、删除、放大预览等操作；点击已放置小卡优先进入编辑，不直接跳转图鉴详情。预览返回后恢复原页面、选中对象和未提交编辑。

### 7.2 封面

封面支持最多一张官方小卡、文字、官方图片 / 符号贴纸、背景和现有画笔。文本、贴纸、画笔不占封面小卡数量，但按当前画布元素安全上限控制，不承诺无限数量。

| 工具 | 产品行为 |
| --- | --- |
| 小卡 | 官方图鉴单选，支持更换、删除、移动、缩放、旋转 |
| 文字 | 内容、字号、字体、颜色、粗体等现有样式，移动、旋转、复制、删除 |
| 贴纸 | 官方上架图片贴纸和符号，支持移动、缩放、旋转、复制、删除 |
| Emoji | 原主 PRD 保留；可通过系统符号贴纸提供，当前没有独立 Emoji 工具页 |
| 画笔 | 沿用当前自由绘制能力，按笔画保存颜色、宽度、轨迹 |
| 背景 | 纯色、渐变、系统图片与颜色素材，支持取色后应用 |
| 图层 | 调整前后关系、选择元素和删除 |
| 撤销 / 重做 / 预览 | 不修改官方小卡源文件 |

字体限系统或平台内置可用字体；本版不上传字体、自定义贴纸或 AI 生成贴纸。贴纸权限按素材会员范围和场景校验。

封面元素采用相对画布位置与尺寸保存；超出画布的部分仅在显示时裁切，保留可编辑元素参数。官方小卡源图不因封面布局被修改。

无封面小卡仍可完成，以背景、名称与已有装饰展示封面。

### 7.3 内页布局与小卡比例

每页 1～9 个固定卡位，沿用系统模板；格数也必须满足当前后台每页上限。

| 格数 | 布局 |
| --- | --- |
| 1 | 1 × 1 |
| 2 | 1 × 2 |
| 3 | 1 × 3 |
| 4 | 2 × 2 |
| 5 / 6 | 2 × 3；5 格使用固定对称排列 |
| 7 / 8 / 9 | 3 × 3；7、8 格使用固定对称排列 |

网格中未使用的位置不生成可编辑卡位。小卡容器参考 55:85 比例，图片等比完整展示；尺寸不同使用留白适配，不为填满卡套裁切图鉴内容。

真实风格显示透明卡套及轻微反光；极简风格显示简洁边界。编辑空位显示“＋”；阅读隐藏编辑入口。

### 7.4 页面和卡位操作

| 操作 | 规则 |
| --- | --- |
| 新增页面 | 在当前页后新增，先校验页数额度 |
| 复制页面 | 新页面和新实例 ID，保留布局内容，校验额度和素材新增使用权限 |
| 删除页面 | 明确受影响小卡数量并确认，不影响图鉴和个人收藏 |
| 页面排序 | 按稳定 page_id 调整顺序，页码只是位置 |
| 清空页面 | 操作文案沿用“清空小卡”；仅清空已放置小卡，保留页面、布局、背景及已有装饰 |
| 更改背景 | 仅应用于所选页，不影响封面和其他作品 |
| 卡位更换 / 移除 | 只更新所选卡位 |
| 移动 / 交换 | 移至空卡位则移动，移至已有卡位则交换 |
| 批量添加 | 按选择顺序填充空位，超出容量按第 9 章处理 |

### 7.5 缩减格数

增加格数保留已有顺序；减少格数时计算超出的实例数并提示。确认后将超出项放入本次编辑的“待放置”区域，允许移至其他页面或撤销。

“完成”之前如仍有未放置项，再次明确确认移除数量；不能在自动保存时无提示丢失这些小卡。待放置区域属于编辑草稿状态，不对访客发布；退出与恢复编辑需保留可恢复状态。

### 7.6 内页装饰：原需求保留

原 V1.0 要求内页自由文字、官方贴纸和 Emoji，元素按页面独立保存并支持移动、缩放等操作，不改变卡位布局。此需求保留在完整 PRD 中。

当前 App 内页主要支持小卡、布局和背景；素材配置支持 PAGE 场景不代表内页装饰编辑器已完成。开发与验收清单必须单列此缺口；本稿建议另排补齐，不把它计为本次模式分离已实现能力。封面画笔能力也不自动扩展为内页画笔需求。

## 8. 卡片模式：独立编辑与阅读

### 8.1 独立内容结构

卡片作品拥有独立的小卡实例列表、主卡、排列顺序、作品故事、展示字段和背景。不得通过隐藏相册页面保存卡片，也不读取其他作品的卡位。

编辑器显示名称 / 故事、添加小卡、已选数量、拖动排序、设为主卡、移除、展示字段、背景、预览和完成；不出现封面自由编辑、单双面、格数或页面管理。

### 8.2 添加、移除与排序

- 从官方图鉴选卡，按选中顺序追加到列表末尾；每次放置产生独立实例 ID。
- 支持多选、单张移除和拖动排序。重复官方小卡需确认；重复实例可以分别排序或设为主卡。
- 上限从服务端权益读取，App 和 API 保持一致；不再通过相册页数扩大容量。
- 移除实例不移除其他重复项，也不改变个人收藏或其他作品。
- 原 V1.0 的“页面顺序 → 卡位顺序”“自定义卡片排序与页面排序同步”等规则全部取消。

### 8.3 主卡与展示封面

一份作品最多一个主卡，关联具体实例。默认首张；设定主卡后，首次打开定位到该卡，不重排整个序列。用户调整顺序时，主卡仍指向原实例。

移除主卡后回退为当前顺序第一张；无剩余小卡则清空主卡。书架和列表以主卡、背景、作品名生成展示封面。卡片作品没有可单独添加官方小卡的自由封面，主卡不重复计数。

### 8.4 故事与展示信息

故事沿用作品简介字段，最多 200 字符，不额外维护两份容易冲突的文本。支持选择展示的官方信息：艺人、组合、来源、类型、版本、发行信息、地区等当前 App 已提供字段。

字段值来自官方图鉴，用户只能控制是否展示，不能在作品内改写图鉴事实。值缺失时省略或统一显示“暂无”，避免出现空标签。API 预留的尺寸字段不等于 App 已有配置入口，若纳入 UI 需单独补齐。

### 8.5 背景

支持纯色、系统渐变、自定义渐变颜色及方向、适用于卡片场景的系统背景 / 颜色素材、图片取色后应用颜色。背景仅影响当前作品。

本机照片用于取色，不直接成为卡片或背景素材；卡片背景不能误展示仅限相册封面的素材。当前借用 PAGE / BOTH 过滤的实现需要改为明确的卡片场景。

### 8.6 阅读与交互

| 操作 / 状态 | 行为 |
| --- | --- |
| 初次进入 | 主卡居中放大，左右卡片缩小叠放 |
| 左 / 右滑动 | 切换下一张 / 上一张，保持卡片之间的顺序关系 |
| 点击侧边卡片 | 切换到该卡片成为焦点 |
| 点击 / 抽出中央卡片 | 进入当前小卡大图及正反面查看状态 |
| 翻至背面 | 有背面时展示；无背面时提示“暂无背面图片”，不显示空白假背面 |
| 收回 / 关闭预览 | 返回原焦点和轮播位置 |
| 查看图鉴详情 | 跳转官方详情，返回恢复焦点 |
| 返回作品列表 | 保留列表位置与筛选状态 |

保持原图比例，使用透视、缩放、阴影和图层表达立体感；动画期间防止冲突手势导致焦点错乱。访客无编辑权限；空作品展示引导，只有作者可以添加小卡。

不提供进入相册模式、翻页阅读或页面目录的入口。

查看官方图鉴详情及“点击侧卡仅聚焦”是原需求保留的待补行为；当前卡片舞台没有独立图鉴详情入口，侧卡点击会直接进入抽出状态，不能将本节全部交互标为现有已完成。

## 9. 共用官方图鉴选卡器

### 9.1 数据与筛选

选卡范围为当前可用官方图鉴小卡，不要求已收藏。复用组合、艺人和来源关系；支持搜索小卡名称及相关信息、本命筛选、组合、艺人、来源类型 / 具体来源、个人已收藏 / 全部等现有筛选。

原主 PRD 列出的 Album、Event、Collection、Merchandise 等以当前图鉴来源字典和实际关联字段为准，不为相册另建一套来源分类。组合条件取交集，无结果时可清除条件。

当前 App 无“官方系列”“周边类型”独立筛选入口；原需求保留，后续确认映射现有来源筛选还是补齐主数据及筛选入口。

网格展示缩略图、名称、必要标识和选中状态；详情入口提供正反面、组合、艺人、来源等信息。无背面不展示可用的背面按钮。

### 9.2 分场景确认

| 来源 | 选择方式 | 确认结果 |
| --- | --- | --- |
| 相册封面 | 单选 | 替换 / 新增唯一封面小卡 |
| 相册空卡位 | 单选或批量 | 填入当前页空卡位，超出项明确处理 |
| 卡片作品 | 单选或批量 | 按选中顺序新增独立实例，按剩余卡片容量校验 |
| 取色 | 单选可分析的官方图 | 只分析颜色，不新增作品实例或个人收藏 |

相册批量添加超出当前页空位时，允许继续增加页面或仅填当前页；新增页必须符合页数额度。仅填当前页后的剩余小卡进入待放置区，可继续放到其他页面；最终完成时仍有剩余，才明确确认移除，不能静默截断。

卡片作品容量不足时提示可添加数量，要求调整选择或明确确认仅添加可容纳部分，不自动创建另一份作品。

## 10. 按场景使用素材与图片取色

### 10.1 App 素材入口与场景对应

App 从当前编辑位置进入对应的素材选择器；每个入口只获取该场景已开放的素材。支持 ALL / PRO 和 PRO 锁定预览，具体内容、排序和状态由对应后台场景管理页面决定。

| 使用场景 | App 入口与可选内容 | 应用范围 | 对应后台页面 |
| --- | --- | --- | --- |
| 书架主题 | 书架设置 → 主题；只选整套书架主题 | 用户书架，不修改作品内部 | 书架主题管理，见 17.2 |
| 相册封面 | BOOK 封面编辑 → 背景 / 贴纸；背景内区分纯色、渐变、图片 | 当前作品封面 | 相册封面素材管理，见 17.3 |
| 相册内页 | BOOK 内页编辑 → 背景；内页贴纸入口待编辑器补齐 | 当前内页 | 相册内页素材管理，见 17.4 |
| 卡片背景 | CARDS 编辑 → 背景；区分纯色、渐变、图片 | 当前卡片作品的轮播背景 | 卡片背景管理，见 17.5 |

颜色、渐变和贴纸归属具体使用场景，不给用户展示跨场景的全部素材库。卡片模式不提供自由贴纸画布；书架主题选择不出现封面、内页或卡片背景选项。

同一图片文件可以在后台多个场景中分别建立素材条目，但各条目的状态、排序、会员范围独立；用户作品也不因此同步。取色得到的个人配色属于当前编辑配置，不自动进入后台系统素材库。

### 10.2 历史使用规则

- 使用素材时保存必要的渲染快照；正常下架、替换素材图片或会员到期不直接改变已保存的视觉。
- 已有实例可保留并调整位置、尺寸等；不能新增不可用素材的实例。
- 删除并保存后，重新添加按新增使用校验；旧客户端或撤销操作也不能绕过服务端权限。
- 整份作品、页面、贴纸复制均属于新增使用；包含下架或无权使用的 PRO 素材时，阻止并指出具体素材，用户替换后再复制。
- 官方图鉴图片失去展示权限不适用“素材普通下架仍可保留显示”规则，按图鉴权限处理；必要的强制撤图需同步清理公开预览和缩略图。

### 10.3 图片取色

入口位于颜色 / 背景编辑控件，支持从本机照片或可分析的官方小卡提取颜色。展示提取结果及当日、当月剩余次数，用户选择颜色应用到当前目标。

| 项目 | 规则 |
| --- | --- |
| 成功计次 | 成功返回一次分析结果扣 1 次，同时计入日额度和月额度 |
| 失败计次 | 无效图片、全透明图片、无权限图片及服务端分析失败不扣次 |
| 重试 | 客户端超时或响应丢失时，以同一请求 ID 确认结果；已成功记录的分析返回原结果，不重复扣次 |
| 应用颜色 | 使用已获得的颜色不重新分析，不重复扣次 |
| 时间口径 | Asia/Shanghai 自然日、自然月；当任一额度用尽时阻止新的分析 |
| 照片限制 | 沿用最大 15 MB、2400 万像素；只用于分析，不保存为图鉴素材 |
| 官方图片 | 必须当前可用且进入受管理存储；未入库的远程图明确提示不可分析，失败不扣次 |
| 并发 | 服务端原子计数，防止并发超扣或透支额度 |

模式说明页中的示例配色不调用取色服务、不扣用户次数。当前原生照片选择器仍需按交付记录补充人工验收，不能仅凭分析接口通过就视为完整端侧验收。

## 11. 相册模式阅读与展示设置

### 11.1 阅读状态

首次进入展示封面；向左或点击下一页进入内页，第一页返回时展示封面。支持目录 / 缩略图定位，返回图鉴详情后保留原页。

| 状态 | 展示 |
| --- | --- |
| 封面 | 居中独立展示封面与名称 |
| 单面 | 每次一页；真实风格保留书脊连接、轻微阴影和半展开效果 |
| 双面 | 左右两页按顺序展开，中间书脊，左右页可以使用不同格数 |
| 极简 | 减少材质、反光和阴影，保留页序与翻页交互 |

奇数页末尾允许有视觉空白占位，但不自动增加真实页面、不占额度；作者需要在该位置添加内容时须先执行新增页面并校验容量。

翻页动作期间防止重复触发；不足距离的手势回弹。低性能设备可简化动画，不能造成页码错乱。

### 11.2 单面 / 双面规则

这是相册模式内部的阅读配置，可以在相册设置中调整。切换前展示编排示意，说明实际页数不变。

例如 4 页相册：单面顺序 P1、P2、P3、P4；双面顺序 P1/P2、P3/P4。回到单面仍为原来的 4 页。单双面调整不新建页面、不复制小卡、不改变实例 ID、不触发页数截断。

删除旧 V1.0 中“双面转单面超额后确认截断”的规则。任何需要拆页的未来功能都属于另一个编辑操作，不得借单双面调整执行。

当前已实现单双面配置和翻页交互；切换前编排示意、跟手翻页与回弹细节属于原需求保留或优化目标，需补齐设计和验收。

### 11.3 小卡预览

阅读中点击小卡打开大图弹层，默认正面，可查看已有背面及图鉴详情。编辑中点击小卡先选中，通过“放大预览”查看大图，避免误跳转。

两种入口返回后恢复原页面和编辑状态。不提供“切换卡片模式”。

## 12. 草稿、自动保存与发布

### 12.1 保存与冲突

- 编辑操作先更新本地草稿，沿用约 700 ms 防抖云保存；展示保存中、已保存、失败重试状态。
- 网络失败保留本地内容，退出后可恢复；本地草稿按账号隔离，切换账号不得泄露上一个账号的作品。
- 使用 revision 检查并发；旧版本提交不能覆盖新版本。冲突时先保留本地备份，再引导读取最新版本。
- 离线时可继续可支持的本地编辑；需要联网的选卡、素材或取色给出说明，不显示虚假成功。
- 用户点击预览，使用当前编辑草稿，不发布；返回后保留编辑位置与内容。

### 12.2 状态分离

| 状态维度 | 取值 / 含义 |
| --- | --- |
| 内容状态 | DRAFT 草稿 / PUBLISHED 已完成发布 / DELETED 已删除 |
| 可见性 | PRIVATE 私密 / PUBLIC 公开 |
| 运营状态 | NORMAL 正常 / RESTRICTED 限制公开 / OFFLINE 下架 |
| 复核 | 是否有待处理申请、最近复核结果 |
| 恢复后发布阻断 | 待作者重新发布，避免直接恢复旧违规版本 |
| 作品类型 | BOOK / CARDS，创建后固定，与上述状态无关 |

私密作品也可以是 PUBLISHED，表示用户完成编辑；不能把“已发布”直接理解为任何人都可访问。草稿不进入访客列表。

### 12.3 完成与发布

点击“完成”校验名称、类型结构、有效权限、实际新增数量、官方小卡状态、重复与移除确认。允许合法的空作品完成。历史超额内容按保留规则处理，不因重新发布被截断。

成功后保存可编辑内容并生成发布快照；后续继续编辑不自动覆盖访客所见内容。访客、收藏和分享读取最新合法发布版本。

封面和列表预览仍须保留可编辑源数据。原主 PRD 的“异步生成封面缩略图”保留为待补能力；当前可按结构化数据渲染，不将后台能够预览等同于已有服务器合成服务。生成缩略图失败不丢失编辑内容，可回退为结构化预览或默认占位。

## 13. 公开、主页、点赞、收藏与分享

### 13.1 公开访问

作者默认私密，可设置公开。访客可访问需要同时满足：作品存在且未删除、已有合法发布版本、设为公开、运营允许、无恢复后发布阻断；主页列表还应尊重作者“公开我的卡册”设置。

链接不是权限凭证。变为私密、删除、被限制或下架后，详情、列表、搜索、收藏、分享均统一限制访问，不能通过历史链接继续打开。

### 13.2 点赞与收藏

- 同一用户对同一作品最多一条有效点赞；支持取消；不能给自己的作品点赞或收藏。
- 收藏只保存对他人公开作品的引用，不复制内容，不增加自己的作品额度，不加入实体小卡收藏。
- 原作者再次发布后，收藏访问展示最新合法发布版本。
- 原作品不可访问时展示明确状态；保留引用供用户移除，不展示过期内容。

### 13.3 收藏分组

沿用收藏分组：创建、修改名称和公开设置、将收藏移入分组、全部及未分组视图。访客只可查看公开分组内仍然可访问的作品；不能通过公开分组暴露私密或下架作品。

当前 App 没有完整分组删除入口，本版不将其列为现有已完成能力。两种作品均可进入同一分组，类型只用于识别和筛选。

### 13.4 分享

沿用 App 链接 `fanos://app/digital-albums/{id}`，按作品 ID 读取固定类型并进入对应阅读器。只分享可访问的已发布内容；作者当前未发布编辑不进入分享内容。

本版不承诺独立网页阅读、分享长图、海报或图片导出。后续若新增这些载体，仍须遵循固定类型、发布版本和访问权限。

## 14. 后台数字相册：结构与权限

### 14.1 模块结构

保留“后台管理 → 数字相册”入口，作品管理与额度管理沿用。将当前“主题与系统素材”的混合管理页调整为“素材管理”分组，下设四个独立页面。分组只作为导航，不再承载全部素材混排的列表。

| 导航位置 | 独立管理内容 |

| 数字相册 → 作品管理 | 查询、分类型预览、关联举报、限制公开 / 下架 / 恢复、复核与日志 |

| 数字相册 → 素材管理 → 书架主题 | 书架视觉与主题配置、书架效果预览、主题上下架 |
| 数字相册 → 素材管理 → 相册封面 | 封面背景、配色和封面贴纸，各自列表与表单 |

每个场景页面拥有自己的筛选、列表、新增、编辑和预览流程。进入页面后创建的素材自动归属该场景，不再要求运营在通用表单中多选“适用场景”。

| 操作 | 系统管理员 admin | 运营管理员 operation_admin | 内容运营 content_operator |
| --- | --- | --- | --- |
| 查看作品、详情、关联举报及日志 | 支持 | 支持 | 不开放 |
| 限制公开、下架、处理复核及恢复 | 支持 | 支持 | 不开放 |
| 查看额度及四个场景的素材列表 / 预览 | 支持 | 只读 | 不开放 |
| 修改全局配置、用户会员授权 | 支持 | 不允许 | 不允许 |

## 15. 后台作品管理与审核

### 15.1 查询与列表

查询沿用名称、用户 ID、内容状态、创建时间，增加作品类型；沿用运营状态、待复核等条件。重置清空筛选；刷新保留条件；失败支持重试。

| 字段 | 展示口径 |
| --- | --- |
| 作品 / 作者 | 名称、作品 ID、作者昵称与用户 ID |
| 类型 | 相册模式 / 卡片模式，本次新增明确列与筛选 |
| 数量 | BOOK 显示实际页数及内页卡数；CARDS 仅显示卡片实例数 |
| 可见性 | 公开 / 私密 |
| 内容与运营状态 | 分开展示草稿 / 已发布 / 已删除和正常 / 限制公开 / 下架 |
| 复核 | 待复核、最近结果、待作者重新发布 |
| 互动与举报 | 点赞、收藏、关联举报信息按实际返回展示 |
| 时间 | 创建、更新、最近发布时间明确标注；筛选日期使用创建时间；现有 published_at 每次发布会更新，不代表首次发布时间 |
| 操作 | 查看、更多处理操作；无修改作品类型 |

当前列表最多返回最近更新的 200 条，部分运营状态 / 待复核筛选在已返回集合内执行。此限制须在界面说明，不能宣称全量查询、全量统计或完整分页。

本次新增类型筛选应由服务端在取数上限之前执行，避免只过滤已取回的 200 条。全量服务端分页另列优化，不将当前列表用作收益或全量审核报表。

### 15.2 详情与预览

打开详情重新读取服务端数据，展示基础信息、当前可预览版本、作品内容、关联举报、复核和操作日志。

| 作品情况 | 默认预览 |
| --- | --- |
| 已发布作品日常查看 | 最新发布快照 |
| 未发布草稿 | 当前编辑内容 |
| 处理待复核申请 | 该申请提交时的不可变快照 |

相册预览包括书架展示、封面、页面、文字、贴纸、画笔、背景、卡位、单 / 双页、缩略图、缩放和正反面。卡片预览包括独立序列、主卡、背景、故事和信息展示。

后台只能按作品所属类型预览，移除 BOOK / CARDS 切换。视图选择版本不是作品类型切换。现有复核快照不等于已实现通用“编辑版本与发布版本对比”工具。

### 15.3 运营处理

| 动作 | 结果 | 必填内容 |
| --- | --- | --- |
| 限制公开 | 阻止他人访问；作者保留查看与编辑 | 原因分类、处理说明 |
| 下架 | 停止公开展示与分享；保留作者编辑数据 | 原因分类、处理说明 |
| 驳回复核 | 维持限制，反馈需修改内容 | 面向作者的明确原因 |
| 恢复 | 清除运营限制，并进入待作者重新发布 | 原因分类、处理说明（必填），保留处理记录 |

恢复不会自动公开原私密作品、复活已删除作品，也不会直接展示旧违规快照或替作者发布最新编辑。

处理时明确选择需要结案的关联举报，只能选择属于当前作品的举报；不能因处理作品而将无关举报全部结案。保存处理人、时间、前后状态、原因和关联记录。

### 15.4 作者修改与复核

作者看到限制原因 → 修改并成功保存 → 提交复核 → 固化提交时的内容及 revision → 后台查看该快照 → 恢复或驳回 → 恢复后作者主动完成发布 → 按可见性恢复访问。

同一 revision 重复提交应返回原申请；存在待处理申请时不再生成第二个并行申请。提交后继续编辑不覆盖审核快照，审核员必须看到自己正在处理的版本。

沿用当前作品级解除限制规则：复核快照用于审核和追溯，恢复后作者可以发布当前编辑版本，仍执行正常发布校验。当前未强制要求发布 revision 等于审核通过 revision；如后续要求仅发布审核通过版本，应单独增加版本一致性规则。

客户端与服务端都应展示“待复核”“复核未通过”“已恢复，待重新发布”等必要状态。内置拦截词等现有内容校验继续沿用，但不宣称已有完整自动图像审核能力。

## 17. 后台素材管理：按使用场景拆分

**本次调整。** 以下四个场景分别设计管理页面及需求，不以“一个全部素材列表 + 场景筛选”代替拆分。上传、权限校验等底层能力可以复用，运营操作始终在具体场景中完成。

### 17.1 管理结构与条目归属

| 场景页面 | 管理对象 | 页面内分类 | 场景标识（建议） |
| --- | --- | --- | --- |
| 书架主题 | 用户书架整体视觉主题 | 主题列表 | SHELF |
| 相册封面 | BOOK 封面可使用的素材 | 背景、贴纸；背景再分纯色 / 渐变 / 图片 | ALBUM_COVER |
| 相册内页 | BOOK 内页可使用的素材 | 背景；贴纸分类待内页编辑能力补齐后开放 | ALBUM_PAGE |
| 卡片背景 | CARDS 轮播场景的背景 | 纯色、渐变、图片 | CARD_BACKGROUND |

每个条目只归属一个场景，场景由当前页面自动带入并只读展示，保存后不可改成另一场景。颜色、背景和贴纸是场景内的素材形式，不再作为跨场景混排的一级管理入口。

同一图片可以由多个场景条目引用，文件存储可复用；各条目使用独立业务 ID，分别保存名称、状态、排序、会员范围、锁定预览及展示配置。修改或下架某场景条目不联动其他场景。需要用于另一个场景时，在目标页面新建条目并单独预览、上架，不直接变更原条目归属。

### 17.2 场景一：书架主题管理

**运营目的：** 为用户的卡册陈列区域提供不同书架风格；主题影响用户书架整体，不影响作品封面、内页或卡片背景。

**后台入口：** 数字相册 → 素材管理 → 书架主题。

| 页面部分 | 需求 |
| --- | --- |
| 筛选 | 主题名称 / ID、上架状态、会员范围 |
| 列表 | 书架效果缩略图、主题名称、主题 ID、会员范围、状态、排序、内置标识、更新时间 |
| 新增 / 编辑 | 主题名称、主题视觉配置或背景图片、预览、会员范围、锁定预览、排序；归属固定为书架 |
| 预览 | 在模拟书架中展示多份作品，检查 2 列 / 3 列陈列及不同主题对作品辨识度的影响 |
| 操作 | 查看预览、保存草稿、编辑、上架、下架；删除受生命周期规则限制 |
| App 对应 | 书架设置 → 主题；选择后更新该用户书架，作品内部不变 |

主题视觉使用当前书架渲染支持的配置。图片支持 JPG / PNG / WebP，单张不超过 10 MB；新增字段不得变成自由编辑书架组件的功能。

下架后不再供用户新选，已应用主题按历史快照保留；主题文件替换不直接改变旧用户的已保存视觉。没有可选主题时使用内置默认主题。

### 17.3 场景二：相册封面素材管理

**运营目的：** 提供 BOOK 封面设计时使用的背景和装饰。此页面不管理官方小卡图鉴、用户输入的文字或画笔笔画。

**后台入口：** 数字相册 → 素材管理 → 相册封面。

**页面结构：** 分为“背景”“贴纸”两个分类页签，各自有筛选、列表和新增按钮；不使用同时包含背景和贴纸所有字段的通用表单。

| 分类 | 列表与筛选 | 新增 / 编辑字段 | 预览与 App 落点 |
| --- | --- | --- | --- |
| 封面背景 | 名称 / ID、纯色 / 渐变 / 图片、状态、会员范围；列表显示效果、形式、状态、排序及更新时间 | 名称、背景形式；纯色填颜色，渐变填颜色组及方向，图片上传背景图；会员范围、锁定预览、排序 | 以封面画布叠加示例标题及一张官方小卡预览；App 封面编辑 → 背景 |
| 封面贴纸 | 名称 / ID、图片 / 符号、状态、会员范围；列表显示贴纸预览、形式、状态、排序及更新时间 | 名称、图片或符号内容；会员范围、锁定预览、排序 | 透明底检查与封面放置效果预览；App 封面编辑 → 贴纸 |

背景图片支持 JPG / PNG / WebP，贴纸图片支持 PNG / WebP 并保留透明度，均不超过 10 MB。表单只展示所选素材形式需要的字段，上传图片时不能要求运营同时填写符号内容。

发布封面素材后，仅进入封面对应选择器；不自动开放给内页或卡片作品。后台预览中的示例小卡和文字只用于检查效果，不随素材一并加入用户作品。

### 17.4 场景三：相册内页素材管理

**运营目的：** 提供 BOOK 内页背景和配色，让固定卡位在不同页面风格下保持清晰。内页装饰仍按原主 PRD 保留项处理。

**后台入口：** 数字相册 → 素材管理 → 相册内页。

| 页面部分 | 需求 |
| --- | --- |
| 当前管理内容 | 内页纯色、渐变、图片背景 |
| 筛选 | 名称 / ID、背景形式、状态、会员范围 |
| 列表 | 内页效果预览、名称、ID、背景形式、状态、会员范围、排序、更新时间 |
| 新增 / 编辑 | 名称、纯色 / 渐变 / 图片对应配置、会员范围、锁定预览、排序；归属固定为相册内页 |
| 预览 | 在内页中叠加 1 / 4 / 9 格示例卡位，可查看单面 / 双面与真实 / 极简效果，检查背景与卡套的可辨识度 |
| App 对应 | 相册内页编辑 → 背景，仅应用当前页，不自动修改封面或其他内页 |
| 贴纸后续扩展 | 内页装饰编辑器补齐后，再开放“内页贴纸”分类，使用独立列表、表单和内页预览 |

图片支持 JPG / PNG / WebP，单张不超过 10 MB。预览中的页数、卡位数只用于检查，不改变用户权益或作品数据。

当前 App 尚无完整内页贴纸 / 文字 / Emoji 工具，不能通过后台上架条目就宣称该能力可用。尚未接通的内页贴纸保留为迁移记录或草稿，不在 App 新增选择器中放出，也不开放无对应端侧能力的上架操作。

### 17.5 场景四：卡片背景管理

**运营目的：** 提供 CARDS 立体叠放展示时的背景，突出中央主卡及左右层叠效果。

**后台入口：** 数字相册 → 素材管理 → 卡片背景。

| 页面部分 | 需求 |
| --- | --- |
| 筛选 | 名称 / ID、纯色 / 渐变 / 图片、状态、会员范围 |
| 列表 | 轮播场景缩略图、背景名称、ID、背景形式、状态、会员范围、排序、更新时间 |
| 新增 / 编辑 | 名称、对应颜色 / 渐变颜色与方向 / 图片、会员范围、锁定预览、排序；归属固定为卡片背景 |
| 预览 | 用至少 3 张示例小卡展示中央主卡、左右层叠、文字可读性；可左右切换，检查不同焦点效果 |
| App 对应 | 卡片作品编辑 → 背景，应用当前作品的轮播场景 |
| 发布范围 | 仅 CARDS 卡片背景选择器，不进入相册封面或内页素材列表 |

图片支持 JPG / PNG / WebP，单张不超过 10 MB。该页面不出现单双面、页数、格数、封面贴纸或自由装饰字段。效果预览不创建作品、不消耗取色次数。

### 17.6 四个页面共用的操作规范

以下仅复用业务规范和底层能力，不合并四个场景的管理列表与表单。

| 事项 | 规则 |
| --- | --- |
| 名称与 ID | 名称必填，业务 ID 唯一；新增时重复 ID 报错；已有条目的场景和素材类型不可改 |
| 会员范围 | 各场景条目独立设置 ALL / PRO；同一文件在不同场景可有不同范围 |
| 锁定预览 | 单独控制无使用权用户是否可预览，不授予添加权限 |
| 排序 | 仅在所属场景及该素材分类内生效，不影响其他场景 |
| 状态 | 草稿 DRAFT / 上架 PUBLISHED / 下架 OFFLINE；各条目独立管理 |
| 上架前检查 | 必填内容完整、图片可访问、形式与场景匹配、端侧功能已接通、可正常预览 |
| 上下架提示 | 明确本次影响的场景、素材名和新增使用范围，说明旧实例保留规则 |
| 保存与退出 | 保存失败保留输入并给出原因；切换分类、场景或离开页面前提醒未保存内容 |
| 刷新与筛选 | 每页独立保存当前筛选状态；刷新只更新当前场景，不带入另一场景的条件 |
| 上传 | 文件进入受管理存储；类型、大小和解析失败明确提示；失败不将条目标成已上架 |
| 权限 | 按 14.2 执行；只读角色可查看和预览，不能执行写操作 |

草稿只供后台管理，不能在 App 作为新增素材。下架停止新增使用，历史渲染按第 10 章保留。曾上架素材不能退回草稿；只有从未上架、从未使用的草稿可以删除，内置素材不可删除。

修改素材文件不替换用户已保存实例的快照。删除某个允许删除的场景条目，不得删除仍被其他场景条目或历史实例引用的底层文件。

本版不增加跨场景批量上架、素材 Tag、定时上下架、素材版本管理界面或自动运营通知。

### 17.7 旧素材按场景归类与兼容

当前统一列表使用 SHELF / BACKGROUND / COLOR / STICKER 类型，以及 COVER / PAGE / BOTH 场景。迁移按原类型与实际用途归类，不能把 BOTH 当作新卡片模式的授权。

| 旧素材 | 新管理位置 | 迁移处理 |
| --- | --- | --- |
| SHELF | 书架主题 | 保留原主题及用户使用记录 |
| COVER 背景 / 颜色 / 贴纸 | 相册封面对应分类 | 按封面用途迁入，保留原状态与权益 |
| PAGE 背景 / 颜色 | 相册内页背景 | 按内页用途迁入，保留原状态与权益 |
| BOTH 背景 / 颜色 | 分别建立相册封面、相册内页条目 | 各自业务 ID、状态、排序和权益；初始值可继承原配置，后续互不联动 |
| PAGE / BOTH 贴纸的内页用途 | 相册内页迁移记录 / 待开放分类 | 保留历史实例；App 内页装饰未完成前不向新增选择开放 |
| 曾被卡片作品使用的 PAGE / BOTH 背景 / 颜色 | 历史使用保留；新卡片背景需单独确认 | 原实例及快照保留；运营确认适合后在卡片背景页面建立独立条目，默认草稿，单独上架 |

保存原素材 ID、使用位置与新场景条目 ID 的映射，保持已有作品和用户主题引用可追溯。对拆分前已有实例，不因生成新条目而改变视觉或认定为用户新增使用；复制作品或重新添加时按目标场景的新条目权限校验。

归类不明确或同一旧记录包含不兼容内容时进入核对清单，不自动上架到多个场景。场景拆分不会修改已有作品的类型、卡片数量或取色用量。

## 18. 核心数据与接口约束

本章规定业务数据关系，字段名称为建议命名，不要求研发机械新增同名物理表。可复用共同作品主表，但不能继续复用同一份页面数据模拟两种作品。

### 18.1 业务实体

| 实体 | 核心信息 |
| --- | --- |
| 作品 | ID、作者、名称、简介、固定 work_mode、可见性、内容状态、运营状态、revision、时间 |
| 相册内容 | 封面配置、页面、固定卡位、单双面、视觉风格；仅 BOOK |
| 卡片内容 | 独立实例、排列顺序、主卡实例、背景、展示字段；仅 CARDS |
| 发布快照 | 作品 ID、类型、发布 revision 与完整展示内容 |
| 复核申请 | 作品 ID、类型、提交 revision、不可变快照、审核结果与原因 |
| 场景素材条目 | 独立条目 ID、固定所属场景、素材形式、名称、状态、排序、会员范围、展示配置；底层文件可复用 |
| 素材实例 | 场景条目 ID、编辑参数、必要渲染快照；历史实例保留旧素材 ID 与迁移映射 |
| 互动关系 | 点赞、收藏、收藏分组；不拷贝作品主体 |
| 用户偏好 / 权益 | 书架主题、列表偏好、会员与到期时间、配置及用量 |

### 18.2 类型数据约束

| 字段 / 对象 | BOOK | CARDS |
| --- | --- | --- |
| work_mode | 固定 BOOK | 固定 CARDS |
| cover / pages / slots | 使用 | 不创建，不允许写入 |
| display_type / visual_style | 使用 | 不适用 |
| card_instances | 不使用独立轮播序列 | 每项具有稳定 instance_id 和 card_id |
| featured_instance_id | 不适用 | 可空，必须引用本作品实例 |
| card_order | 不适用 | 只含本作品实例，每项恰好一次 |
| display_fields / card_background | 不适用 | 本作品独立配置 |

相册卡位 ID 和卡片实例 ID 都与官方 Card ID 分离。删除实例同步清理排序及主卡引用；未授权跨作品实例、重复排序 ID、遗漏实例等请求需拒绝或明确规范化，不能误改其他作品。

原 `card_view.default_mode` 不再作为可修改的作品类型开关；旧 `featured_slot_id` 等通过迁移映射到卡片实例。

### 18.3 接口要求

| 业务操作 | 本次要求 |
| --- | --- |
| 创建作品 | 一次请求提交类型和对应基础配置；原子创建；支持防重复提交 |
| 查询列表 / 详情 | 返回固定类型、对应数量和权限状态；支持类型筛选 |
| 保存草稿 | 校验 revision、作品类型、所有者、额度与素材使用权 |
| 相册封面 / 页面接口 | 只接受 BOOK；对 CARDS 明确返回类型不支持 |
| 卡片实例 / 排序 / 主卡接口 | 只接受 CARDS，不再转写相册页和卡位 |
| 作品设置 | 不允许修改 work_mode；BOOK 才允许单双面和视觉风格 |
| 复制 | 同类型、新 ID、私密草稿，校验额度和素材权限 |
| 发布 / 复核 | 快照包含固定类型；校验状态，不能绕过恢复后发布流程 |
| 公开 / 收藏 / 分享查询 | 统一权限和最新发布版本口径 |
| 场景素材查询与维护 | 按固定场景查询和写入；每个场景返回自己的列表与配置，拒绝从一个场景入口修改另一场景条目 |
| 素材应用与复制 | 校验条目场景与实际使用位置匹配，并校验该条目的状态、会员范围；不能仅凭共用文件地址绕过 |
| 取色 | 维持请求幂等、并发保护、成功计次 |

已有 `/albums` 等路由可以继续使用；卡片实例操作是否新增子路由由技术设计确定，本 PRD 不将建议 API 当成已发布接口。旧客户端提交模式切换或跨类型内容时应收到明确的不兼容提示，不能静默转换或吞掉数据。

## 19. 存量作品与兼容方案

**本次必需，具体归类策略为建议待确认。** 当前作品是共享页面的双展示结构，不能只删 App 切换按钮而不处理存量内容。

### 19.1 归类建议

1. 每份旧作品只生成一份新结构作品，保留原 ID、作者、公开设置、时间、互动、举报及运营状态，不批量复制为两份。
2. 建议优先参考已发布快照中的默认模式，未发布作品参考当前编辑默认模式；只有归类明确的记录才能自动迁移。
3. 发布版本与编辑版本模式冲突、默认值缺失、存在另一视图重要设计等情况进入核对清单，不凭猜测丢弃内容。产品 / 数据负责人在切换前确认归类及保留方式。
4. 完整保留迁移前编辑内容、发布内容和复核快照作为可恢复档案，包括不再用于新阅读器的封面、装饰、页面和排序。档案不作为日常跨模式切换入口。

### 19.2 内容转换

| 目标类型 | 保留与转换 |
| --- | --- |
| BOOK | 保留封面、所有内页、卡位、装饰、单双面与风格；旧卡片配置归档，不生成可编辑卡片作品 |
| CARDS | 依据旧有效卡片顺序生成独立实例；缺少显式排序时按旧页面 / 卡位顺序；重复小卡保留，旧主卡映射到实例，保留背景、故事与展示字段 |

卡片作品不得因为新默认上限为 15 就删掉第 16 张及以后内容。历史超额标记后允许阅读和修改既有内容，新增按当前额度校验。迁移前后卡片数量、顺序、主卡及图像引用需逐项核对。

旧作品的编辑、发布、复核快照需要各自转换与关联，不能用最新编辑覆盖原发布或审核内容；复核中的作品可先保留冻结审核记录，待适配完成后再开放处理。

### 19.3 发布与回退要求

- 先备份、生成影响清单，在副本验证，再协调服务端、App、后台版本切换。
- 迁移失败不写入半套结构，不新增作品额度占用；保留可回退的原数据与映射。
- 旧客户端不得修改已迁移作品的类型或以旧共享结构覆盖新数据；必要时提示更新客户端。
- 保留原分享 ID、点赞和收藏引用；登录账号和素材权限不因迁移重置。
- 本文只提出迁移要求，没有执行迁移、修改业务数据或发布应用。

## 20. 异常、可靠性与性能

### 20.1 异常处理

| 场景 | 处理 |
| --- | --- |
| 创建前取消或只查看预览 | 不创建作品、不占额度 |
| 创建请求重复 / 超时重试 | 返回同一结果，不生成重复作品 |
| 请求改模式或写入另一类型内容 | 明确拒绝，原数据不变 |
| 超作品 / 页数 / 卡片额度 | 展示当前量和上限，不部分成功或静默截断 |
| 格数缩减有溢出 | 告知数量、待放置、最终移除确认 |
| 单双面调整 | 页数和卡片数不变，不弹截断提示 |
| 图鉴小卡不可用 | 保留实例占位；遵循图片展示权限 |
| 图片加载失败 | 占位及重试，不删除实例 |
| 没有背面 | 清晰提示或隐藏入口，不伪造背面 |
| 保存失败 / 网络中断 | 保留本地修改和可恢复待放置项 |
| 多设备冲突 | 拒绝覆盖，保留本地备份，再重新加载 |
| 素材下架 / 到期 | 保留旧实例，限制新增与复制 |
| 作品被限制或下架 | 作者可改、可按流程复核；访客不可访问 |
| 复核恢复 | 等待作者主动发布，不自动展示旧内容 |
| 取色失败 / 重试 | 失败不扣，幂等重试不重复扣 |
| 后台配置减少 | 先影响预览与确认，历史不删 |

### 20.2 性能与兼容

- 默认 PRO 相册支持 20 页 × 9 格，即 180 个内页小卡实例；若后台提高上限，应以允许配置的边界验证，不将 180 写成系统绝对最大值。
- 书架采用轻量缩略展示；阅读只预加载当前及相邻页 / 卡片，避免一次加载全部原图。
- 卡片历史迁移超过 15 张仍须正常渲染，不能以新建上限作为历史阅读数组限制。
- 相册与卡片的动画、图片缓存按需释放；连续操作不能让页码、焦点和数据顺序分离。
- iOS / Android 不同尺寸下，小卡完整、双面不超出安全区域、装饰相对位置稳定；手势与系统返回冲突时提供可点击操作。
- 预览与正式阅读遵循同一布局数据；后台与 App 的字体、Emoji 可能有平台差异，应核验关键构图而非承诺逐像素一致。
- 权限变化应使公开缓存及缩略图按相同权限失效；私密内容不得因共享缓存被其他用户读取。

| 编号 | 场景 | 预期结果 |

## 23. 讨论项与后续更新方式

### 23.1 需讨论的连带口径

用户已明确“两种模式完全分离、创建后不可切换、创建增加预览说明、素材管理按需求场景拆开”，不再将这些要求列为待确认。以下为本稿提供的推荐方案：

| 编号 | 讨论项 | 本稿建议 | 影响 |
| --- | --- | --- | --- |
| Q1 | 两种作品如何计算总数 | 继续共用普通 10 / PRO 30 的作品总额度 | 保持原权益规模；两类不各自再获得一套额度 |
| Q2 | 卡片作品容量 | 普通 / PRO 初始均 15，后台分档配置；历史超额保留 | 沿用当前 App 使用习惯，先不额外推导付费差异 |
| Q3 | 卡片作品书架封面 | 使用主卡 + 背景 + 名称自动展示，不提供自由封面编辑 | 让两类创建和编辑工具保持清晰 |
| Q4 | 存量默认类型 | 发布快照优先，草稿用编辑默认值；冲突核对、完整归档 | 需要迁移清单后才能确认所有旧作品的最终归类 |
| Q5 | 原主 PRD 未实现项排期 | 内页装饰、异步缩略图单列补齐；不混入模式分离已完成范围 | 保留完整产品目标，便于决定本次开发边界 |

以上讨论项已在相关章节明确标注。确认后直接更新对应条款与验收标准，避免只在聊天中保留决定。

本地测试迁移确认（2026-10-22）：用户最后明确选择“卡片”。以下五份未记录模式的旧作品归为 `CARDS`，不是 `BOOK`：`album-starlit`、`album-live`、`album_3bbee60909ad4c8c827d28e0ef04c3f2`、`album_b457430d925d439ab50bce0748bb4809`、`album_974dedc8a11f4f78b7ec906d682a56b2`。此确认仅适用于本地测试库这些 ID，不将其他未知作品或生产数据自动归类；迁移保留原始编辑、发布与复核快照。页面手动验收由用户进行，当前不发布生产服务器、Android 或 Git。
