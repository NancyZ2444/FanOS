### 首次版本的用户闭环

1. **找卡和收藏**：登录／选择本命 → 浏览或搜索图鉴 → 查看小卡详情 → 标记拥有或加入心愿 → 回到卡库管理。
2. **扫描入库**：拍摄／导入照片 → 检测并选择小卡 → 匹配已有图鉴 → 确认结果 → 收藏或标记拥有。未匹配小卡当时尚不能按后续版本的完整审核补充流程自动闭环。
3. **卡册创作**：选择小卡 → 创建卡册并排版 → 保存草稿／预览 → 发布公开或私密作品 → 查看和管理作品；公开内容可进入互动流程。
4. **运营供给**：后台录入或导入图鉴 → 核对图片、归属和来源 → 审核发布 → App 可浏览，符合条件的图片进入扫描匹配范围。
